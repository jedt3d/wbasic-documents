61 · ROT13 and a Message That Comes Back

Download main.wbas

ROT13 shifts English letters halfway around a 26-letter alphabet. Applying it twice restores the original text. We use it to practice walking a String and preserving characters outside the chosen alphabet, not to hide passwords or secrets.

Try it

Use wb with the native toolchain from Getting Started in the downloaded file’s folder:

wb check main.wbas --json
wb run main.wbas

Uryyb JOnfvp! ไทย 123
Hello WBasic! ไทย 123

Thai text, numbers, spaces, and the exclamation mark remain unchanged. The second line is produced by transforming the first result again, not by printing a saved copy of the original variable.

How the matching tables work

' Original WBasic teaching example; inspired by Al Sweigart project 61.
Procedure Rotate(text As String) As String
  Let alphabet As String = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz"
  Let shifted As String = "NOPQRSTUVWXYZABCDEFGHIJKLMnopqrstuvwxyzabcdefghijklm"
  Let result As String = ""
  For Each letter As String In text
    Let replacement As String = letter
    For index As Integer = 0 To alphabet.Length - 1
      If letter = alphabet[index] Then
        replacement = shifted[index]
        Break
      EndIf
    Next
    result += replacement
  Next
  Return result
EndProcedure

Procedure Main()
  Let message As String = "Hello WBasic! ไทย 123"
  Let encoded As String = Rotate(message)
  PrintLn(encoded)
  PrintLn(Rotate(encoded))
EndProcedure

alphabet and shifted are equal-length strings. Characters at the same position form a replacement pair. Both upper- and lowercase letters are listed, so the program need not change the message’s case first.

For Each reads one Unicode scalar at a time. Each pass initializes replacement to the original character, then searches the table. An unmatched character therefore survives without a list of every other language. A match uses the same index in the replacement table and exits the search loop with Break. A linear search is clear enough for a 52-character table.

Tests that mean something

Transforming twice should restore the input, but that property alone is insufficient: a program that changed nothing would also pass. Check known pairs such as A → N, n → a, Z → M, and unchanged 123.

Try an empty string and Thai text mixed with emoji. Scalars outside the tables should remain intact. Do not call String length the number of visible characters: Thai vowels and tone marks can involve multiple scalars. As an exercise, read with ReadLine() and use If Let to distinguish EOF from a blank line; Core I/O already supports that extension.

Origin

Inspired by Project 61: ROT 13 Cipher by Al Sweigart. The WBasic code and paired-table explanation were written anew, including an example that preserves Thai text.
