66 · Simple Substitution Cipher

Download main.wbas

A simple substitution cipher pairs A–Z with a shuffled alphabet. Each original letter always maps to the same replacement. This program encrypts one fixed uppercase line and decodes it, showing how the same map works in both directions when source and destination alphabets are exchanged.

Try running it

wb check main.wbas --json
wb run main.wbas

DTTZ QZ FGGF!
MEET AT NOON!

The map must be one-to-one

' Original WBasic teaching example inspired by Al Sweigart project 66.
Procedure Translate(message As String, fromAlphabet As String, toAlphabet As String) As String
  Let answer As String = ""
  For Each letter As String In message
    Let replacement As String = letter
    For position As Integer = 0 To fromAlphabet.Length - 1
      If letter = fromAlphabet[position] Then
        replacement = toAlphabet[position]
        Break
      EndIf
    Next
    answer += replacement
  Next
  Return answer
EndProcedure

Procedure Main()
  Let alphabet As String = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
  Let key As String = "QWERTYUIOPASDFGHJKLZXCVBNM"
  If alphabet.Length <> key.Length Then
    PrintLn("invalid key")
    Return
  EndIf
  For index As Integer = 0 To key.Length - 1
    Let found As Boolean = False
    For letterIndex As Integer = 0 To alphabet.Length - 1
      If key[index] = alphabet[letterIndex] Then
        found = True
        Break
      EndIf
    Next
    If Not found Then
      PrintLn("key must be A-Z")
      Return
    EndIf
    For earlier As Integer = 0 To index - 1
      If key[index] = key[earlier] Then
        PrintLn("duplicate key letter")
        Return
      EndIf
    Next
  Next
  Let message As String = "MEET AT NOON!"
  Let secret As String = Translate(message, alphabet, key)
  PrintLn(secret)
  PrintLn(Translate(secret, key, alphabet))
EndProcedure

alphabet is the reference order; key contains replacements at matching positions. For example, A maps to Q and B to W. Translate searches fromAlphabet for each character and takes the corresponding position from toAlphabet. An unmatched character such as a space or ! remains unchanged. To decode, Main supplies key as the source and alphabet as the destination.

Before using it, the program checks that key has 26 letters, that each is A–Z, and that none repeats. Duplicate replacements would make decoding ambiguous: several original letters could become the same letter. Validating the map is part of the algorithm.

Experiment

Put Q twice in the key to get duplicate key letter; insert a digit to get key must be A-Z. For ABC XYZ, check each letter’s mapped position by hand. To support lowercase, decide whether it needs another key or case conversion with case restoration. This version leaves lowercase unchanged.

Repeated-letter patterns remain visible in this cipher, so it is for learning mappings rather than storing secrets.

Scope and origin

Inspired by Project 66: Simple Substitution Cipher by Al Sweigart. The WBasic code was written anew for fixed uppercase text, without a random key or interactive mode.
