Small WBasic Projects Roadmap

81 project ideas and the boundaries to verify before completing each lesson

Small WBasic Projects: Chapter Map

This book uses the ideas behind all 81 projects in The Big Book of Small Python Projects by Al Sweigart to practice WBasic with newly written explanations and code. Each entry links to the original chapter for attribution and comparison. The table distinguishes lessons with source from plans awaiting verification; evidence for one project does not stand in for another.

Core language (29) identifies lessons using available integers, strings, Array, line input, and printing. Verification needed (47) identifies work requiring tests of a lesson-specific PRNG, supporting data, or TUI events and rendering. Missing API (5) identifies a key capability of the original format absent from the public v0.3 API; an explicitly limited adaptation may still be possible. The 29 core lessons have source examples checked and run on Windows ARM64 as recorded on the verification page. The other 52 are individual project plans without downloadable WBasic source.

Random generation, calendar/wall-clock access, Math.Sin/Cos, audio, and TTS are not part of the public v0.3 surface checked in this specification/compiler revision. A handwritten pseudorandom generator can provide reproducible results, but is not a system random API. A TUI timer measures intervals within a session, not the calendar date and time.
