このリファレンスが扱うコンパイラとツールのバージョン

コンパイラ／ランタイム 0.1.0 と拡張機能 0.2.1：CLI とエディターで揃えた現行リリース

実験的な非公開 v0.1.0 リリース に合わせ、2026 年 10 月 2 日に更新しました。Windows ARM64 と macOS ARM64 の現行コンパイラ／ランタイムは 0.1.0、対応する VS Code 拡張機能は 0.2.1 です。CLI、ポータブル ZIP、VS Code で選択するコンパイラは同じ版を使います。以前の v0.0.1/v0.0.2 は過去のダウンロードとして変更せず残します。

コンパイラのリリース番号、言語設計の draft v0.3、サイトの公開バージョンは別です。コンパイラのリリースマニフェスト には固定済みのソースと両 ZIP のハッシュが記録されています。コンパイラは心を読めませんが、wb --version で解決する謎は意外に多いものです。

拡張機能とプロトコルパッケージの版は独立しています。インストール後にウィンドウを再読み込みし、WBasic: Show Toolchain Status で選択したコンパイラが 0.1.0 を示すことを確認します。wbasic.compilerPath を指定すれば、ポータブル ZIP のコンパイラを選べます。対応するランタイムとリンカーも同じパッケージのまま使います。Rust のソースや開発用インストールからコンパイラをビルドする場合は、ネイティブのツールチェーン／SDK が必要です。

エディター機能とその境界

ライブ診断とナビゲーションは、未保存のソースを含むプロジェクトスナップショットを使います。補完は可視性を検査し、単純な宣言済みの受け手のフィールドやメソッドを、コンパイラのバインディング識別情報で解決します。ファイル間の名前変更は、変更後のスナップショットをコンパイラで検証します。カタログは 31 項目 / 10 カテゴリ / 61 教材ファイルです。WORM M2/M3 はモジュールごとコピーでき、Check/Build に対応します。データベースの実行には明示的なパスが必要です。M4 UI はモジュールの準備が必要なリポジトリ内の参照資料で、Copy Example の対象外です。

任意の式の連鎖、型別名の完全な対応、組み込み String/Array メンバーの補完は未完成です。デバッグや整形は対応機能として掲げていません。記録された統合では、ARM64 の各環境で プロトコル 71 件、エディター 120 件、実際の VS Code Extension Host 11 件が通り、Rust テストは Windows 519 件 / macOS 507 件が通りました。既存の opt-in の除外テストは別に扱います。リリースでは、対応するネイティブ release ビルドと、ZIP 展開後のテストを追加しています。過去の本の全サンプルを再実行したという意味ではありません。

パッケージのインストールと確認

展開前に、ZIP の SHA-256 を対応するファイルとリリース記録に照合します。Install-And-Test.ps1 または Install-And-Test.sh を実行し、セッション用 PATH ヘルパーを使います。基本のコンパイルに Node は不要です。Node はプロトコルアダプター用、VS Code はエディター利用時の任意の要素です。入門、WORM SQLite、拡張機能ガイド を参照してください。

ネイティブの開発ホストでのパッケージ検証は、Windows 11 Pro 25H2 ARM64（PowerShell 5.1 と 7）、macOS 26.6.2 ARM64 を対象にしています。Unicode、コンパイル・実行・ビルド、ゼロ件でないテスト検出、請求額の検査が通っています。ただし、SDK のない新規マシンでの受け入れを証明するものではありません。再配布通知、署名・公証、本番利用の権限は未完了で、noSdkDistribution は false のままです。

受け入れと過去のサンプル

規範的な draft v0.3 は引き続き 72 Passed / 23 Planned / 0 Deferred で、WORM の独立したマイルストーンは含みません。R6 D1–D5 は記録された範囲で通っています。Windows OSC52 の成功確認には固定した非公開 Microsoft ConPTY 接続先を使い、一部の OS 同梱ホストでは依然としてタイムアウトします。NativeLocal と OSC52 は別経路です。Linux ARM64 とネイティブ x86_64 には、受け入れ済みの実行証拠がありません。

小さな WBasic プロジェクトの本は、記録されたリビジョンで ネイティブ検証済み 29 例 / 計画段階 52 教材を保っています。このリリースによって、計画中の教材や、人間・AI のコストに関する主張が自動的に検証済みになることはありません。過去の証拠は元のバージョンとハッシュを保ち、現在の識別情報はリリース記録とサイトのマニフェストが示します。
