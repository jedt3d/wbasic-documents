検証済みの WBasic v0.3 の動作を扱うリファレンス

WBasic リファレンス

言語、標準ライブラリ、公開 API を扱う、バージョン管理されたガイド

本ごとに読む

このリファレンスは、言語の規則、標準ライブラリ、モジュールの API を分けて説明します。現在の動作については、検証済みの WBasic v0.3 の機能を扱います。提案は、動作の証拠が得られるまで開発用ドキュメントに置きます。

現在の対象範囲

このリファレンスは、コンパイラ／ランタイム 0.1.0 の実験的な非公開リリースと ローカル検証済みの拡張機能 0.2.3 に対応します。公開済み ZIP には引き続き 0.2.1 が同梱されています。CLI、ポータブル ZIP、VS Code が選択するコンパイラは同じ版を使い、言語設計の draft v0.3 とは別に管理します。インストールや古いマニフェストの更新前に コンパイラとツールのバージョン を確認してください。

各章は、現在の実装で検証した言語、標準ライブラリ、公開 API の明確な規則、小さな例、境界条件、関連する診断を示します。計画段階や延期した機能には明示的な表示を付けます。リファレンスがコンパイラの代わりに小説を書いてはいけません。

タイ語が正本です。英語版と日本語版は利用者の依頼で翻訳し、実装と検証の範囲を同じに保っています。

表記の約束

キーワードと API 名には、コンパイラが受け付ける正確な綴りを使います。完全なプログラムには Main が一つあり、断片には必要な文脈を示します。型、値、エラーには、他言語の思い込みではなく WBasic 自身の定義を使います。

01 はじめに 小さな Billing Time プロジェクトを作って実行し、その後 SQLite を使う別のアプリを学びます。 本を開く 02 小さなWBasicプロジェクト集 小さなWBasicプログラムの設計・記述・検証を練習する日本語版 本を開く 03 WBasic 拡張機能ガイド VS Code でのプロジェクト作成、実行、ビルド、テスト、モジュール管理を体験する実践ガイド 本を開く 04 言語リファレンス WBasicプログラムの構文と意味 本を開く 05 標準ライブラリ WBasic プログラムで利用できる標準モジュール、型、手続き 本を開く 06 API リファレンス 公開 API のシグネチャと契約をモジュール別に確認します。 本を開く 07 WBasic のデザインとアイデンティティ WBasic とドキュメントに共通の個性を与える考え方、色、書体、ロゴ、マスコット 本を開く
