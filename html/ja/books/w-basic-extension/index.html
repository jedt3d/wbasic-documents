WBasic 拡張機能ガイド

VS Code でのプロジェクト作成、実行、ビルド、テスト、モジュール管理を体験する実践ガイド

対応するバージョンを選びます。 1〜12 章は、公開済みの実験的な非公開コンパイラ／ランタイム 0.1.0 プレリリース、拡張機能 wbasic-dev.wbasic@0.2.1、プロトコルパッケージ 0.0.2 を扱います。Windows/macOS ARM64 ZIP と同梱 VSIX は、固定済みソースに照合して独立に再確認した上で公開しています。パッケージのガイド から始めてください。古い非公開 0.0.2 パッケージには拡張機能 0.1.0 が含まれ、1〜12 章の編集手順は実行できません。

この開発用ガイドは VS Code 向け WBasic 拡張機能を、空のワークスペースから最初のプロジェクトを作り、補完と診断を使ってソースを書き、モジュールを管理し、ビルドして Test Explorer でテストする、一続きの作業で教えます。

本全体で MyFirstWBasic という小さなプロジェクトを使います。各章の 練習と 確認項目で、画像をクリックしながらコンパイラの機嫌に期待する代わりに、その手順が動いたか判断できます。

ここで扱うのは、Windows 11 ARM64 の VS Code 1.139.1、macOS ARM64 の 1.140.0 で検証した wbasic-dev.wbasic@0.2.1 開発用拡張機能です。対応する同梱コンパイラ、ランタイム素材、リンカーでは、ホスト SDK を使わず Run と Development Build が動きます。ソースからのビルドにはネイティブ SDK が必要です。SDK のない新規ホストでの受け入れと本番配布は未完了です。

対応するプレリリースでは VS Code、拡張機能、コンパイラを準備する から始めてください。

01 1 · VS Code、拡張機能、コンパイラを準備する 開発用 VSIX をインストールし、wb を接続して、正しいツールチェーンが認識されることを確認する 02 2 · 最初のプロジェクトを作る New Project で、マニフェスト、ソース、テストのひな形を手作業なしで作成する 03 3 · ワークスペースとマニフェストを見て回る プログラムを書く前に、App.wproj、Outline、Projects の画面を理解する 04 4 · 言語を理解する編集機能で書く 最初のタイ語プログラムで、補完、Hover、引数のヒント、Outline を練習する 05 5 · 診断を読み、クイックフィックスを使う 構文・型・実行基盤のエラーを区別し、キーワードの大文字小文字を安全に修正する 06 6 · ナビゲーションとリファクタリング 定義、参照、ワークスペースのシンボル、コンパイラが検証する複数ファイルの名前変更を使う 07 7 · モジュールと依存パス Include や隠れた検索パスを使わず、マニフェストでローカルモジュールを追加する 08 8 · 実行、ビルド、タスク ソースとプロジェクトを実行し、Debug・Release の開発成果物と問題マッチャーを使う 09 9 · Test Explorer でテストする コンパイラの識別情報を保ち、ネイティブ WBasic テストを検出、実行、選択、中止する 10 10 · サンプルと TUI の作業手順 検証済みサンプルを開く・コピーし、決定的なテンプレートから TUI や Jobs を始める 11 11 · 設定、信頼、問題の調べ方 必要な設定だけを行い、ログを読み、すべてをリセットせずに原因の層を見つける 12 12 · 日常の作業手順と限界 編集・確認・テスト・ビルドの循環を整理し、利用できる機能と計画段階の機能を分ける 13 0 · 対応する 0.1.0 パッケージを選ぶ 実験的な非公開 ARM64 プレリリースと、対応する VS Code 拡張機能 0.2.1 をインストールする
