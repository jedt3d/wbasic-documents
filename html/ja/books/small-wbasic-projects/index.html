小さなWBasicプロジェクト集

小さなWBasicプログラムの設計・記述・検証を練習する日本語版

本書はAl Sweigartの『The Big Book of Small Python Projects』にある課題の着想を翻案し、WBasicの説明と例を新たに執筆したものです。 実際に作りながら学べる題材を集めてくださった著者に感謝します。Invent with Python — The Big Book of Small Python Projectsで原著を直接読み、そこにあるリンクから著者を支援してください。

本書は独立して制作したWBasicの学習書であり、原著の公式翻訳でも、著者がWBasicを推奨しているという主張でもありません。出典を探しやすいように課題番号を保っていますが、1番から読む必要はありません。

『はじめに』から小さな課題へ

本書は『はじめに』の次に読む2冊目です。ソースファイルとは何か、wbをどう使うかを知ったら、これらの小さな課題で入力から出力までの流れを1章で追えます。短いコードにも境界条件への注意は必要です。短いぶん、読まない言い訳が減るだけです。

タイ語版が原版です。この日本語版は完成したタイ語版と編集レビューを踏まえ、英語版を参照して制作しました。

読み進める道筋を選ぶ

入れ子のループを練習するなら掛け算表から始め、次にひし形で文字の行を組み立てます。約数と素数に進むと、規則を手続きに分ける練習になります。

状態の扱いに慣れたら、フィボナッチ数列、コラッツ数列、ROT13、三目並べの中心的な規則を試します。各章は対象範囲の違いを説明します。用意した手順の再生を対話式ゲームとして、範囲を限った実験を一般的な証明として提示しません。

81課題のロードマップには、すべての課題、状態、必要な準備を示します。

この版には教材のコードがある29課題と、計画段階の52課題があります。実装済みの教材でも、元の規則を先に教えるために計算1つや手順の再生に範囲を絞ったものがあります。原著のプログラムの全機能を備えるとは主張しません。

文章の課題には、文字の絵、シーザー暗号、鍵の総当たり、リート表記、ピッグ・ラテン、大小文字の交替、換字式暗号があります。数の課題には基数変換と7セグメント数字があります。ゲームの課題には、四目並べ、マンカラ、三目並べ、ハノイの塔、水桶問題の中心的な規則があります。コマンド入力や画面操作を足す前に、データ構造を練習できます。

ファイルをダウンロードし、実行前に状態を読む

実装済みの章はmain.wbasのダウンロードで始まり、同じファイルのコードを表示します。書き込み可能なフォルダーに保存し、『はじめに』の開発用ツールチェーンを用意してから、wb check main.wbas --jsonとwb run main.wbasを実行します。これらの例は、SDKのないマシン向けの配布物が完成した証拠にはなりません。

計画段階の章は本文の前に状態を示し、まだ存在しないソースの代わりに計画をダウンロードできます。未執筆、検証待ち、実際に不足しているAPIを区別します。便利な組み込みコマンドがないからといって課題が不可能とは限りません。言語の基本機能で同じ手順を書けるなら、章にその旨を記します。

教材の検証方法

2026年10月1日の拡充では、8章（指定した年と月から作るカレンダー）、13章（ライフゲームの1世代）、73章（数独の検査器）に詳しい説明と下書きコードを加えました。各draft.wbas.txtは読んでさらに検証するためのもので、実行が確認されたプログラムではありません。3章とも計画段階の52章に含まれ、検証済みの例は29のままです。数独の解法、乱数による問題生成、対話式TUIは未完成です。

ライブラリ要求はwbasic-languageリポジトリのdocs/proposals/small-projects-library-feature-requests.mdに別途記録します。安定したSWP-FR-*のIDは教材の必要性と提案を結びます。IDがあるだけで、そのAPIが存在したり実装が承認されたりしたことにはなりません。

コードのある各章には期待する結果、入力の境界、試すべき変更を記します。ソースの検査と実行は別の手順です。コンパイラと結果は検証記録に示します。対応プラットフォームの主張はその証拠に従います。1台での成功を、すべての環境での成功とは見なしません。

課題番号と出典リンクは着想の元を示します。WBasicのコードと説明は新たに書きました。ダウンロードには原著の文章、画像、Pythonソース集は含まれません。
