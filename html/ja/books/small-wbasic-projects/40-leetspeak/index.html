小さなWBasicプロジェクト集

40 · 文字をリート表記に変換する

読みやすく、決定的な文字置換表を作る

ダウンロード main.wbas

目的と範囲

リート表記は、Aを4、Eを3に替えるように、文字の見た目を変えて遊びます。この章では固定の文WBasic is neat!を、A、E、I、O、S、Tの6つの規則で変換します。複数の候補からランダムに選ぶ版と違い、結果は毎回同じです。小さな表なら各文字を確認し、規則にない文字がそのまま残ることも分かります。

準備と実行

main.wbasをダウンロードし、そのフォルダーで端末を開きます。開発用マシンにはwbと対応するネイティブSDKおよびランタイムが必要です。

wb check main.wbas --json
wb run main.wbas

runは実行前にコンパイルとリンクを行います。wbを自分でビルドする場合は、まずWBasicリポジトリのルートでcargo build --workspace --lockedを実行します。記録済みの例ではコンパイラ2614b37を使用しています。統合済みのコンパイラ0.0.2のwb buildはデバッグ／リリース構成の.wprojプロジェクト向けであり、単独の.wbasファイル向けではありません。実験用パッケージにはリンク用ツールが含まれます。SDKのない新しいマシンでの受け入れは未完了です。次の出力を確認してください。

WBasic is neat!
WB451c 15 n347!

Procedure Leet(message As String) As String
  Let result As String = ""
  For Each letter As String In message
    Let lower As String = letter.ToLower()
    If lower = "a" Then
      result += "4"
    ElseIf lower = "e" Then
      result += "3"
    ElseIf lower = "i" Then
      result += "1"
    ElseIf lower = "o" Then
      result += "0"
    ElseIf lower = "s" Then
      result += "5"
    ElseIf lower = "t" Then
      result += "7"
    Else
      result += letter
    EndIf
  Next
  Return result
EndProcedure

Procedure Main()
  Let message As String = "WBasic is neat!"
  PrintLn(message)
  PrintLn(Leet(message))
EndProcedure

文字ごとに置換を読む

LeetはFor Eachで文字列をたどり、規則を選ぶため現在の文字を小文字にします。したがってaとAは同じ規則です。一致すれば数字を追加し、そうでなければ元の文字を追加します。WBasicではWとBは残り、a、s、iは4、5、1になります。result += ...で蓄積することが重要です。毎回result = ...にすると最後の文字の置換しか残りません。

これは暗号ではなく、一般に曖昧さなく元へ戻せません。元からある4とAから置き換えた4は、後では同じに見えます。この版は空白、句読点、タイ文字、規則にないすべての文字を保ちます。.ToLower()は規則を選ぶだけで、結果全体を小文字にするわけではありません。

次に試すこと

  1. B→8を追加し、実行前に新しい2行目を予測しましょう。
  2. 元からある数字4を含め、復号が曖昧になる理由を説明しましょう。
  3. 元の文字と置換後の文字の組を配列に保存し、多くのElseIf分岐なしで表を増やせるようにしましょう。
