81 · 水桶と段階ごとの状態変化

ダウンロード main.wbas

3つの桶には8、5、3リットル入ります。目標はどれか1つの桶に4リットルを入れることです。桶を満たす、空にする、または注ぎ元が空になるか注ぎ先が満杯になるまで別の桶へ注ぐ操作ができます。この例は用意した操作の列を再生し、目標に達したところで止まります。プレイヤーの入力を解析せずに状態遷移を学べます。

実行してみる

wb check main.wbas --json
wb run main.wbas

8L=0 5L=0 3L=0
8L=0 5L=5 3L=0
8L=0 5L=2 3L=3
8L=0 5L=2 3L=0
8L=0 5L=0 3L=2
8L=0 5L=5 3L=2
8L=0 5L=4 3L=3
goal: 4L

1つの操作を状態変化として読む

' Original WBasic teaching example inspired by Al Sweigart project 81.
Procedure Show(water As Array Of Integer)
  PrintLn("8L=" + water[0].ToString() + " 5L=" + water[1].ToString() + " 3L=" + water[2].ToString())
EndProcedure

Procedure Main()
  Let capacity As Array Of Integer = [8, 5, 3]
  Let water As Array Of Integer = [0, 0, 0]
  ' 0 = fill; 1 = empty; 2 = pour source into target.
  Let actions As Array Of (Array Of Integer) = [[0, 1, 0], [2, 1, 2], [1, 2, 0], [2, 1, 2], [0, 1, 0], [2, 1, 2], [1, 2, 0], [2, 1, 2]]
  Show(water)
  For Each action As Array Of Integer In actions
    Let kind As Integer = action[0]
    Let source As Integer = action[1]
    Let target As Integer = action[2]
    If source < 0 Or source >= 3 Or target < 0 Or target >= 3 Then
      PrintLn("invalid bucket")
      Return
    EndIf
    If kind = 0 Then
      water[source] = capacity[source]
    ElseIf kind = 1 Then
      water[source] = 0
    ElseIf kind = 2 Then
      If source = target Then
        PrintLn("same bucket")
        Return
      EndIf
      Let amount As Integer = water[source]
      Let space As Integer = capacity[target] - water[target]
      If amount > space Then
        amount = space
      EndIf
      water[source] = water[source] - amount
      water[target] = water[target] + amount
    Else
      PrintLn("invalid action")
      Return
    EndIf
    Show(water)
    If water[0] = 4 Or water[1] = 4 Or water[2] = 4 Then
      PrintLn("goal: 4L")
      Return
    EndIf
  Next
  PrintLn("goal not reached")
EndProcedure

capacityには固定した容量、waterには変化する水量を入れます。actionsは操作の種類・注ぎ元・注ぎ先という3つの数によるコマンドの配列です。種類0は満たす、1は空にする、2は注ぐ操作です。注ぐときは、注ぎ元の水量と注ぎ先の空き容量の小さい方をamountとし、同じ量を片方から引き、もう片方へ足します。注ぐ操作では水の総量が保存されます。

配列に触れる前に、プログラムは両方の添字を検証し、同じ桶へ注ぐ操作を禁じます。各操作の後で状態を表示し、それから目標を調べるため、達成した状態が見えます。5リットルの桶から、すでに2リットル入っていて残り1リットルだけ受け入れられる3リットルの桶へ注ぐと、5リットルの桶に4リットルが残ります。

境界の確認

満杯の桶を満たしても容量を超えてはいけません。空の桶から注げばamount = 0で変化しません。最初の操作で注ぎ元の添字を3または-1にした場合、配列を読む前にinvalid bucketを示すはずです。さらに進めるなら、すでに見た状態を記録しながら最短の解を探索します。各状態は桶ごとの水量で識別できます。

範囲と出典

原著の課題81：Water Bucket Puzzle（Al Sweigart）に着想を得ました。この新しいWBasicコードは手順の再生と目標判定であり、対話式ゲームでも最短解の探索でもありません。\n
