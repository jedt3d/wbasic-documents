ソーステキスト、名前、リテラル、行の構成

WBasicによるUTF-8、識別子、コメント、数値、文字列、論理行の読み方

文字コードと大文字・小文字

WBasicファイルはUTF-8を使い、バイト順マークがあってもなくても構いません。LFとCRLFの意味は同じです。診断には元のファイル、行、列、ソース範囲が保たれます。

キーワードと識別子は大文字・小文字を区別します。Procedure、Let、EndProcedureのように、キーワードは指定された形で書きます。total、Total、TOTALは別々の名前です。

Unicode識別子

名前にはタイ文字やほかの文字体系を使えます。

Procedure ทักทาย(ชื่อ As String) As String
  Return $"สวัสดี {ชื่อ}"
EndProcedure

最初の文字は_またはUnicodeのXID_Start文字でなければなりません。それ以降の文字は_またはUnicodeのXID_Continue文字です。

WBasicは比較前に名前をNFCへ正規化し、制御文字、双方向制御文字、既定で無視される文字を拒否します。キーワードは英語のままです。関連のない文字体系を混ぜた名前には、見た目が似た名前への注意を促す警告が出ることがあります。

論理行とブロック

1つの論理行には1つの文を書きます。WBasicにはセミコロンやコロンによる文の区切りがありません。()、[]、{}の内部でのみ、文を次の行に続けられます。

Let message As String = BuildMessage(
  "WBasic",
  "ภาษาไทย"
)

手続きの呼び出しには常に括弧が必要です。インデントは読み手を助けますが、ブロックは作りません。コンパイラはEndProcedure、EndIfなどの終了キーワードとの対応を使います。フォーマッターは階層ごとに空白2つを使います。

コメントと文書化

文字列の外では、'から行末までが通常のコメントです。///は、空白を除いた論理行の先頭にある場合だけ、次の宣言の文書化コメントになります。

/// คืนคำทักทายสำหรับชื่อที่รับมา
Procedure Greeting(name As String) As String
  Return $"Hello, {name}"
EndProcedure

10進数とその他の数値

各ファイルでは、Unicodeの10進数字を1種類選びます。ASCII数字とタイ数字の両方に対応しますが、無効な条件付きソースや文字列補間内の式も含め、1ファイル内で混ぜることはできません。

' ไฟล์ที่ใช้เลข ASCII
Let total As Integer = 10 + 25

' ไฟล์ที่ใช้เลขไทย
Let ผลรวม As Integer = ๑๐ + ๒๕

Let total As Integer = ๑๐ + 25は拒否されます。16進数と2進数のリテラルは例外で、接頭辞と数字はASCIIです。浮動小数点数はASCIIの.とeまたはEを使いますが、10進数字はファイルの数字の種類に合わせる必要があります。アンダースコアは数字と数字の間にだけ置けます。

10進整数リテラルの型はIntegerです。小数点または指数を持つリテラルの型はFloatです。値を正確に表現できる場合、整数リテラルには期待されるByteまたはFloatの型を与えることもできます。

文字列の形式

通常の文字列では\n、\t、\"、\\などのエスケープを認識します。生文字列はr"..."の形で、バックスラッシュを解釈しません。内部の二重引用符1つは""と書きます。補間文字列は$で始まり、式を波括弧に入れ、二重の波括弧は字面どおりの波括弧を表します。

Let escaped As String = "C:\\work\\main.wbas"
Let raw As String = r"C:\work\main.wbas"
Let report As String = $"{name}: {score} points; {{verified}}"

これらの文字列は1つの論理行に収まります。WBasic 0.3には複数行文字列がありません。
