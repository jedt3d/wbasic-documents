หนังสืออ้างอิง

แยกกฎภาษา โมดูลมาตรฐาน และ signature ของ API เป็นหนังสือคนละส่วน

ใช้คู่มือภาษาเมื่อเขียน source WBasic ใช้หนังสือไลบรารีมาตรฐานเมื่อทำงานกับ Core และโมดูลข้อมูล และใช้คู่มือ API เมื่อต้องการ signature หรือสัญญา error ที่แน่นอน

01 Getting Started เริ่มใช้ WBasic ผ่าน Billing Time ตั้งแต่เครื่องมือ โครงสร้างโครงการ ภาษา และการ compile บน command line 02 Small Wbasic Projects ฝึกคิด เขียน และตรวจโปรแกรมขนาดเล็กด้วย WBasic — ฉบับภาษาไทย 03 WBasic Extension Guide คู่มือใช้ WBasic 0.2.0 กับ VS Code extension 0.3.0 ตั้งแต่ project ถึง editor, run, build และ test 04 คู่มือภาษา ไวยากรณ์และความหมายของโปรแกรม WBasic 05 ไลบรารีมาตรฐาน โมดูล ชนิดข้อมูล และ procedure มาตรฐานที่โปรแกรม WBasic เรียกใช้ได้ 06 คู่มือ API signature และสัญญาการทำงานของ API สาธารณะ แยกตาม module 07 Design and Identity ของ WBasic แนวคิด สี ตัวอักษร โลโก้ และมาสค็อตที่ทำให้ WBasic มีบุคลิกเดียวกันทั้งภาษาและเอกสาร
