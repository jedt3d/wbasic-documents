คู่มือสำหรับพฤติกรรม WBasic v0.3 ที่ตรวจสอบแล้ว

WBasic Extension Guide

คู่มือจับมือใช้ WBasic บน VS Code ตั้งแต่สร้าง project จนถึง run, build, test และจัดการ module

เลือกเวอร์ชันที่เข้าคู่กัน บทที่ 1–12 ใช้ extension wbasic-dev.wbasic@0.2.3 ที่ตรวจกับ development compiler/runtime ในเครื่อง ส่วน private experimental compiler/runtime ที่เผยแพร่เป็นรุ่น 0.1.0 กับ protocol package 0.0.2 VSIX รุ่น 0.2.3 ต้องได้รับแยกต่างหาก: ZIP ARM64 ที่เผยแพร่บรรจุ VSIX รุ่น 0.2.1 ไว้ตามเดิม ยังไม่มี 0.2.3 release หรือ Marketplace เริ่มที่ คู่มือแพ็ก

คู่มือ development ปัจจุบัน สอนใช้ WBasic Extension for VS Code แบบลงมือทำจริง ตั้งแต่เปิด workspace ว่าง สร้าง project แรก เขียน source ด้วย autocomplete และ diagnostics ไปจนถึงจัดการ module, build โปรแกรม และรัน test ผ่าน Test Explorer

เราจะใช้ project เล็กชื่อ MyFirstWBasic เป็นเส้นเรื่องเดียวกันตลอดเล่ม ทุกบทมี ภารกิจฝึกมือ และ จุดตรวจ เพื่อให้รู้ว่าทำสำเร็จจริง ไม่ใช่เพียงกดตามรูปแล้ว หวังว่า compiler จะเห็นใจ

Extension รุ่นที่หนังสืออ้างอิงคือ development payload wbasic-dev.wbasic@0.2.3 ซึ่งตรวจ workflow ของ Command Palette กับ VS Code 1.140.0 บน Windows 11 ARM64 ผล Mac ARM64 และ TUI แบบรับ input ของรุ่น 0.2.3 ยังไม่ได้รันทดสอบซ้ำ เมื่อใช้ compiler, runtime assets และ linker ที่เข้าคู่กันในแพ็ก การ Run และ Development Build ไม่ต้องใช้ SDK ของ host แต่การ build จาก source ยังต้องใช้ native SDK ส่วน fresh no-SDK host acceptance และ production distribution ยังเปิดอยู่

เมื่อใช้ prerelease ที่เข้าคู่กัน ให้เริ่มที่ เตรียม VS Code, extension และ compiler

01 1 · เตรียม VS Code, extension และ compiler ติดตั้ง development VSIX เชื่อม wb และตรวจว่า extension เห็น toolchain ที่ถูกต้อง 02 2 · สร้าง project แรก ใช้ New Project สร้าง manifest, source และ test skeleton โดยไม่ต้องวางไฟล์เอง 03 3 · เดินชม workspace และ manifest อ่าน App.wproj, Outline และ Projects view ให้เข้าใจก่อนเริ่มเขียนโปรแกรม 04 4 · เขียนโปรแกรมด้วย language intelligence ฝึก completion, hover, signature help และ Outline ด้วยโปรแกรมภาษาไทยโปรแกรมแรก 05 5 · อ่าน diagnostics และใช้ quick fix แยก syntax, type และ infrastructure error พร้อมใช้ keyword-case fix อย่างปลอดภัย 06 6 · Navigation และ refactoring ใช้ definition, references, workspace symbols และ compiler-validated rename ข้ามไฟล์ 07 7 · Module และ dependency paths เพิ่ม local module ผ่าน manifest โดยไม่ใช้ Include หรือ search path ที่ซ่อนอยู่ 08 8 · Run, Build และ Tasks รัน source/project สร้าง Debug/Release development artifact และอ่าน problem matcher 09 9 · ทดสอบผ่าน Test Explorer ค้นพบ รัน เลือก และยกเลิก native WBasic tests โดยรักษา identity ของ compiler 10 10 · Examples และ TUI workflow เปิดหรือ copy ตัวอย่างที่ตรวจแล้ว และเริ่ม TUI/Jobs ด้วย deterministic template 11 11 · Settings, Trust และ troubleshooting ตั้งค่าเฉพาะที่จำเป็น อ่าน log และแก้ปัญหาเป็นชั้นโดยไม่รีเซ็ตทุกอย่าง 12 12 · Workflow ประจำวันและขอบเขต สรุปวงจรเขียน–ตรวจ–ทดสอบ–build และแยกสิ่งที่พร้อมใช้จากสิ่งที่ยัง Planned 13 0 · เลือกแพ็ก 0.1.0 ที่เข้าคู่กัน แยกแพ็ก ARM64 ที่เผยแพร่กับ VS Code extension 0.2.3 ที่ตรวจในเครื่อง
