Small WBasic Projects: แผนที่บท

หนังสือนี้นำ แนวคิด ของโครงการทั้ง 81 จาก The Big Book of Small Python Projects โดย Al Sweigart มาฝึกเขียน WBasic ด้วยคำอธิบายและโค้ดใหม่ ลิงก์แต่ละรายการชี้ไปยังบทต้นทางเพื่อให้ผู้อ่านให้เครดิตและอ่านเปรียบเทียบได้ ตารางด้านล่างแยกตัวอย่างที่มี source ออกจากแผนบทที่ยังรอการตรวจ ไม่ใช้สถานะของโครงการหนึ่งแทนหลักฐานของอีกโครงการ

แกนภาษา (29) หมายถึงบทเรียนที่เขียนด้วยจำนวนเต็ม สตริง Array การรับบรรทัด และการพิมพ์ที่มีอยู่ ต้องพิสูจน์ (47) หมายถึงต้องทดสอบ PRNG ที่เขียนในบทเอง ข้อมูลประกอบ หรือเหตุการณ์/การแสดงผล TUI ขาด API (5) หมายถึงความสามารถสำคัญของรูปแบบต้นทางยังไม่อยู่ใน API v0.3; อาจมีฉบับจำกัดที่ซื่อตรงกับข้อแตกต่างได้ กลุ่มแกนภาษา 29 บทมี source ตัวอย่างที่ตรวจและรันผ่านบน Windows ARM64 ตามหน้าหลักฐาน ส่วนอีก 52 บทเป็นหน้าวางแผนรายโครงการ ยังไม่มี WBasic source สำหรับดาวน์โหลด

Random, ปฏิทิน/เวลาจริง, Math.Sin/Cos, เสียง และ TTS ไม่อยู่ใน public v0.3 ที่ตรวจในสเปก/คอมไพเลอร์นี้ การใช้ตัวกำเนิดเลขเทียมที่เขียนเองให้ผลทำซ้ำได้ แต่ไม่เท่ากับ API สุ่มของระบบ ส่วน TUI timer วัดช่วงเวลาใน session ไม่ใช่นาฬิกาวันที่

#โครงการและแนวคิดฉบับ WBasicสถานะสิ่งที่บทต้องอธิบาย/พิสูจน์
1Bagels — เกมเดารหัสสามหลักจากคำใบ้ตำแหน่งตัวเลข (ต้นทาง)ต้องพิสูจน์ต้องเขียนตัวสุ่มแบบ seed คงที่ในบทและตรวจช่วงจำนวนเต็ม; ยังไม่มี public API สำหรับการสุ่ม
2Birthday Paradox — จำลองโอกาสคนเกิดวันเดียวกันในกลุ่ม (ต้นทาง)ต้องพิสูจน์ต้องกำหนดวันเกิดจำลองด้วย PRNG ที่ตรวจแล้ว; ยังไม่มี public API สำหรับการสุ่ม
3Bitmap Message — เติมลวดลายตัวอักษรลงในข้อความภาพพิกเซล (ต้นทาง)แกนภาษาใช้ Array Of String เก็บภาพทีละแถว แล้วรักษาช่องว่างและแทนช่องทึบด้วยอักษรข้อความ
4Blackjack — เล่นไพ่แต้มยี่สิบเอ็ดกับเจ้ามือ (ต้นทาง)ต้องพิสูจน์ต้องสร้างชุดไพ่และการสับด้วย PRNG ที่พิสูจน์แล้ว; ยังไม่มี public API สำหรับการสุ่ม
5Bouncing DVD Logo — ขยับโลโก้ชนขอบจอและนับการชนมุม (ต้นทาง)ต้องพิสูจน์ต้องพิสูจน์ TUI timer, ขนาด viewport และการเรนเดอร์ซ้ำบนเครื่องจริง
6Caesar Cipher — เลื่อนอักษรเพื่อเข้ารหัสและถอดรหัส (ต้นทาง)แกนภาษากำหนดขอบเขตอักษรละตินและคงอักขระอื่นไว้
7Caesar Hacker — ลองทุกระยะเลื่อนเพื่ออ่านข้อความเข้ารหัส (ต้นทาง)แกนภาษาใช้การวนครบ 26 กุญแจและแสดงผลให้เลือก
8Calendar Maker — พิมพ์ปฏิทินรายเดือนจากปีและเดือน (ต้นทาง)ต้องพิสูจน์ต้องเขียนและทดสอบเลขวันในสัปดาห์/ปีอธิกสุรทินเอง; ไม่มี DateTime/Calendar
9Carrot in a Box — เกมสองคนเลือกกล่องจากคำบอกและการหลอกล่อ (ต้นทาง)ต้องพิสูจน์ต้องกำหนดการเลือกกล่องด้วย PRNG; การซ่อนข้อมูลผู้เล่นบนคอนโซลต้องทดสอบ UX
10Cho-Han — พนันผลคี่หรือคู่จากลูกเต๋าสองลูก (ต้นทาง)ต้องพิสูจน์ต้องพิสูจน์ PRNG ลูกเต๋าที่กำหนด seed ได้; ไม่มี public API สำหรับการสุ่ม
11Clickbait Headline Generator — ประกอบพาดหัวจากแม่แบบและชุดคำ (ต้นทาง)ต้องพิสูจน์ต้องสุ่มแม่แบบ/คำด้วย PRNG ที่ทดสอบแล้ว
12Collatz Sequence — ไล่ลำดับหารสองหรือคูณสามบวกหนึ่ง (ต้นทาง)แกนภาษา · บทที่มอบหมายระวัง Integer overflow และหยุดเมื่อถึงหนึ่ง
13Conway’s Game of Life — คำนวณชีวิตบนตารางรุ่นต่อรุ่น (ต้นทาง)ต้องพิสูจน์กฎเซลล์ทำได้ด้วย Array; การเล่นสดต้องตรวจ TUI timer และคีย์
14Countdown — แสดงตัวเลขลดลงตามเวลา (ต้นทาง)ต้องพิสูจน์ใช้ TUI timer ใน session ได้ ต้องตรวจการนับและคืน terminal; ไม่ต้องใช้ wall clock
15Deep Cave — สร้างภาพถ้ำลึกที่ขอบเปลี่ยนไป (ต้นทาง)ต้องพิสูจน์ต้องกำหนด PRNG และพิสูจน์การอัปเดตภาพด้วย TUI timer
16Diamonds — พิมพ์รูปเพชรจากความกว้างแต่ละชั้น (ต้นทาง)แกนภาษา · บทที่มอบหมายตรวจความกว้างคู่/คี่และช่องว่าง
17Dice Math — ฝึกบวกเลขจากแต้มลูกเต๋า (ต้นทาง)ต้องพิสูจน์โจทย์สุ่มต้องใช้ PRNG ที่ทดสอบแล้ว
18Dice Roller — อ่านนิพจน์ทอยลูกเต๋าและรวมแต้ม (ต้นทาง)ต้องพิสูจน์ต้องเขียน parser รูป NdM พร้อมตัวปรับแบบ +K/-K ที่ละได้ และ PRNG โดยตรวจช่วงค่าและ overflow
19Digital Clock — แสดงเวลาปัจจุบันแบบนาฬิกาดิจิทัล (ต้นทาง)ขาด APIไม่มี wall clock/DateTime API; TUI timer อย่างเดียวบอกเวลา ณ ปัจจุบันไม่ได้
20Digital Stream — แสดงสายอักขระไหลบนหน้าจอ (ต้นทาง)ต้องพิสูจน์ต้องพิสูจน์ TUI timer, พื้นที่แสดงผลและ PRNG ที่เลือกอักขระ
21DNA Visualization — วาดเกลียว DNA แบบอักษรตามตำแหน่ง (ต้นทาง)ต้องพิสูจน์ภาพคงที่ทำได้; ภาพไหลต้องพิสูจน์ TUI timer
22Ducklings — แสดงลูกเป็ดหลายตัวเคลื่อนผ่านจอ (ต้นทาง)ต้องพิสูจน์ต้องพิสูจน์ TUI timer, viewport และ PRNG ระยะห่าง
