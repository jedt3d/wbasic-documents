32 · คำถามที่ชวนให้ถามอีก

ฝึกจัดการคำตอบ yes, no และคำตอบที่ไม่ตรงรูปแบบด้วยบทสนทนาจำลอง

ดาวน์โหลด main.wbas

เป้าหมายและขอบเขต

โปรแกรมถามว่าผู้อ่านอยากรู้ความลับไหม ถ้าตอบว่าใช่ก็ถามอีก ถ้าตอบว่าไม่จึงเฉลยว่าความลับคือการถามซ้ำ โจทย์ขำเล็กน้อยนี้ให้ฝึกสิ่งจริงจัง: รับคำตอบหลายรูปแบบ การแยกคำตอบที่ไม่รู้จัก และการจบวงสนทนา รุ่นในบทใช้รายการคำตอบจำลอง yes, Y, perhaps, no ตามลำดับ ไม่รอการพิมพ์สด จึงรันในระบบตรวจบทเรียนได้โดยไม่ติดค้าง

เตรียมและรัน

ดาวน์โหลด main.wbas แล้วเปิดเทอร์มินัลในโฟลเดอร์นั้น โดยใช้ wb บนเครื่องพัฒนาที่มี native SDK และ runtime คู่กัน:

wb check main.wbas --json
wb run main.wbas

run คอมไพล์ ลิงก์ และรัน หากสร้างชุดเครื่องมือจาก checkout WBasic เอง ใช้ cargo build --workspace --locked ที่รากคลังผลิตภัณฑ์ก่อน หลักฐานตัวอย่างนี้ใช้ compiler 2614b37 ส่วน compiler 0.0.2 ที่รวมใน main แล้วมี wb build สำหรับ project .wproj พร้อม debug/release; ไม่รับ standalone .wbas แพ็กทดลองมีเครื่องมือ link เตรียมไว้ แต่ยังไม่มี acceptance บนเครื่องสะอาดที่ไม่มี SDK ผลของบทสนทนาจำลองคือ:

Want the secret? (scripted answers)
> yes
Then ask again...
> Y
Then ask again...
> perhaps
Please answer yes or no.
> no
The secret is to ask again.

Procedure Main()
  Let responses As Array Of String = ["yes", "Y", "perhaps", "no"]
  PrintLn("Want the secret? (scripted answers)")
  For Each answer As String In responses
    PrintLn("> " + answer)
    Let normalized As String = answer.ToLower()
    If normalized = "no" Or normalized = "n" Then
      PrintLn("The secret is to ask again.")
      Break
    ElseIf normalized = "yes" Or normalized = "y" Then
      PrintLn("Then ask again...")
    Else
      PrintLn("Please answer yes or no.")
    EndIf
  Next
EndProcedure

คำตอบมีสามทาง ไม่ใช่สองทาง

เราแปลงคำตอบเป็นตัวเล็กด้วย .ToLower() ก่อนเปรียบเทียบ จึงให้ Y กับ yes เข้าทางเดียวกัน แขนงแรกตรวจ no หรือ n แล้วพิมพ์เฉลยและ Break ออกจากวง แขนงที่สองตรวจ yes หรือ y แล้วให้ถามต่อ คำอื่นอย่าง perhaps ไม่ควรถูกนับเป็นใช่หรือไม่: โปรแกรมแจ้งรูปแบบที่ต้องการและวนไปยังคำตอบถัดไป การไม่ตีความคำตอบที่ไม่รู้จักเองช่วยลดพฤติกรรมประหลาดในโปรแกรมที่รับข้อมูลจริง

For Each เดินรายการจำลองที่มีจำนวนแน่นอน จึงไม่มีโอกาสวนตลอดไปแม้ทุกคำตอบจะเป็น yes ต่างจากเกมถามผู้ใช้จริงซึ่งอาจไม่มีวันจบ ถ้าจะเปลี่ยนเป็น input สด ต้องกำหนดวิธีออก เช่น no, จำนวนครั้งสูงสุด หรือคำสั่งเลิกเล่น และต้องบอกผู้ใช้ก่อน หากรายการหมดโดยไม่พบ no รุ่นนี้จบเงียบหลังคำตอบสุดท้าย; นั่นเป็นข้อจำกัดที่ควรเติมข้อความสรุปเมื่อต่อยอด

ลองต่อ

  1. เพิ่ม YES และ N ในรายการเพื่อทดสอบการแปลงตัวพิมพ์
  2. ย้าย no ไปเป็นคำตอบแรก แล้วทำนายว่ารายการหลังจากนั้นจะถูกอ่านหรือไม่
  3. นับจำนวนครั้งที่ผู้ตอบเลือก yes แล้วพิมพ์เมื่อจบ ระวังอย่านับคำที่ไม่รู้จัก
