Small Wbasic Projects

หลักฐานและขอบเขตของฉบับภาษาไทย

หน้านี้แยกสถานะของหนังสือออกจากสถานะผลิตภัณฑ์ การเพิ่มบทเรียนไม่เปลี่ยน Planned หรือ Deferred ของ compiler/runtime ให้กลายเป็น Passed

วิธีตรวจตัวอย่าง

สคริปต์ verify-small-projects.mjs ในคลังเอกสารตรวจ source ที่ดาวน์โหลดได้ด้วย wb check --json จากนั้นสร้าง object และลิงก์กับ static runtime ที่เข้าคู่กัน อ่าน PE machine field เพื่อยืนยัน ARM64 แล้วรัน executable โดยเทียบ standard output กับผลที่ผู้เขียนกำหนดไว้ ทั้งช่องว่างและลำดับบรรทัดต้องตรงกัน ต่างได้เฉพาะรูปแบบ newline ของระบบ

การตรวจนี้มี timeout และถือว่า exit code ที่ผิดเป็นความล้มเหลว ไม่ใช้เพียง “ไฟล์ถูกสร้างแล้ว” เป็นหลักฐานว่าโปรแกรมทำงาน แต่ไม่ได้ครอบคลุมค่าทุกค่าที่ผู้อ่านอาจแก้ในแบบฝึกหัด แบบฝึกหัดยังเป็นงานที่ต้องออกแบบ test เพิ่มเอง

ขอบเขตแพลตฟอร์ม

ผลตรวจวันที่ 30 กันยายน 2026: 29/29 ตัวอย่างผ่าน source check, การตรวจ PE machine 0xAA64, การรัน native และการเทียบ stdout ตรงกับบทเรียน ตรวจ regression เพิ่มในบท 72 ว่า Kelvin sign K ไม่ถูกแปลงและไม่ขยับจังหวะอักษร ASCII ผ่านแล้ว

ใช้ compiler/runtime ที่สร้างคู่กันด้วย cargo build --workspace --locked จาก source revision 2614b37d681631542de25ffac1d6e6b08d41fcb8 หลักฐาน JSON บันทึก hash ของ compiler, runtime, source แต่ละบท และผลคาดหวังเพื่อให้ตรวจย้อนกลับได้

ดาวน์โหลด windows.json

Hugo 0.167.0 build ผ่าน ตัวตรวจหนังสือยืนยัน 81 บท ลิงก์ดาวน์โหลด source 29 ไฟล์และแผน 52 ไฟล์ พร้อมเครดิตต้นทางและลำดับหนังสือที่สองหลัง Getting Started

ชุดตัวอย่างฉบับนี้ตรวจบน Windows ARM64 ด้วย developer toolchain ไม่ใช่ clean-machine/no-SDK distribution test ยังไม่ได้รันชุดบทเรียนใหม่นี้บน macOS, Linux หรือ native x86_64 จึงไม่อ้างผลข้ามแพลตฟอร์มจากหลักฐานของผลิตภัณฑ์รอบก่อน

สถานะบทที่ยังรอ

บทที่มีเฉพาะ PLAN.md ไม่มี executable ให้ตรวจ ไม่ถูกนับรวมกับตัวอย่างที่รันแล้ว รายการ API ที่ขาดอ้างอิง public surface ณ revision ที่บันทึกไว้ อัลกอริทึมทดแทน เช่น PRNG หรือตารางไซน์ที่เขียนเอง ต้องมีหลักฐานของตัวเองก่อนเปลี่ยนเป็นบทที่พร้อมรัน

ส่วน TUI ต้องตรวจ event, การคืนโหมด terminal และพฤติกรรมบน host จริงเพิ่มเติม การพิมพ์ภาพนิ่งผ่าน stdout ไม่ทดแทนการตรวจ animation และการทดสอบแบบ timeout ไม่ทดแทนความสามารถที่ยัง Deferred

บรรณาธิการ

ผู้ตรวจแยกจากผู้เขียนอ่านครบ 81 บท รวม source ทั้ง 29 ตัวอย่าง ตรวจ API, ความสัมพันธ์ระหว่างคำอธิบายกับ source, ขอบเขตที่ลดจากต้นทาง และภาษาไทย ใช้ gpt-6-sol / medium สำหรับผู้เขียนและบรรณาธิการ โดยผู้ประสานงานรัน native gates แยกต่างหาก

รอบตรวจแก้ผลลัพธ์เริ่มต้นของบทนาฬิกาทรายให้ตรงจำนวนเม็ดทราย แก้ขอบเขต Unicode ของบทตัวพิมพ์สลับ และแก้ placeholder ให้บอกข้อจำกัดเฉพาะโจทย์ การนับถอยหลังถูกย้ายไปกลุ่มรอตรวจ TUI เพราะ timer ที่มีอยู่เพียงพอสำหรับการออกแบบ ไม่ต้องรอ wall clock

ผู้ใช้เลือกให้จบฉบับไทยก่อน และอนุมัติให้แปลอังกฤษในรอบถัดมา รายงานบรรณาธิการที่ลิงก์ด้านล่างบันทึกผลของฉบับไทย ไม่ใช่ผลตรวจภาษาอังกฤษหรือการรัน native รอบใหม่

ผลบรรณาธิการรอบสุดท้าย: ผ่าน ไม่มีประเด็นค้าง รายงานแยกสิ่งที่บรรณาธิการตรวจเองออกจากผล native ที่ผู้ประสานงานรันอย่างชัดเจน
