07 · ลองทุกคีย์ของรหัสซีซาร์

ถอดข้อความด้วยคีย์ครบ 26 ค่า แล้วให้คนอ่านเลือกข้อความที่มีความหมาย

ดาวน์โหลด main.wbas

เป้าหมายและขอบเขต

เมื่อไม่รู้คีย์ของรหัสซีซาร์ เราไม่จำเป็นต้องเดาสุ่มจากความรู้สึก ตารางอักษร A–Z มีตำแหน่งเลื่อนที่ต่างกันเพียง 26 ค่า จึงลองถอดด้วยคีย์ 0 ถึง 25 ทั้งหมดได้ บทนี้ใช้ข้อความคงที่ PHHW DW QRRQ! ซึ่งสร้างจากบทก่อนหน้า และแสดงทุกคำตอบให้คนอ่านตัดสินว่าอันไหนเป็นภาษาอังกฤษที่อ่านรู้เรื่อง โปรแกรมไม่ได้มีตัวตรวจภาษาอัตโนมัติ คำว่า “เจาะรหัส” ในที่นี้หมายถึงการไล่ครบพื้นที่คีย์เล็ก ๆ เท่านั้น

เตรียมและรัน

ดาวน์โหลด main.wbas แล้วเปิดเทอร์มินัลในโฟลเดอร์นั้น บนเครื่องพัฒนาที่มี wb และ native SDK/runtime คู่กัน:

wb check main.wbas --json
wb run main.wbas

run คอมไพล์และลิงก์ก่อนรัน หากสร้างเครื่องมือเองให้ใช้ cargo build --workspace --locked ที่รากคลังผลิตภัณฑ์ก่อน wb build ยังไม่ใช่คำสั่งผู้ใช้ ผลมี 26 บรรทัดเรียงตามคีย์ ตัวอย่างช่วงแรกและช่วงท้ายซึ่งระบุค่าตรงตามผลคือ:

ทุกบรรทัดในกรอบเป็นผลจริงที่ควรได้ รวมทั้งคีย์ที่ยังอ่านไม่เป็นคำ

Procedure Decode(message As String, key As Integer) As String
  Let alphabet As String = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
  Let result As String = ""
  For Each letter As String In message
    Let changed As String = letter
    For position As Integer = 0 To alphabet.Length - 1
      If letter = alphabet[position] Then
        changed = alphabet[(position + 26 - key) Mod 26]
        Break
      EndIf
    Next
    result += changed
  Next
  Return result
EndProcedure

Procedure Main()
  Let cipher As String = "PHHW DW QRRQ!"
  For key As Integer = 0 To 25
    PrintLn("key " + key.ToString() + ": " + Decode(cipher, key))
  Next
EndProcedure

จากตัวถอดหนึ่งคีย์สู่การลองครบทุกคีย์

Decode ค้นตำแหน่งตัวอักษรใน alphabet เหมือนตัวเข้ารหัส แต่เลื่อนไปด้านหลังด้วย position + 26 - key แล้ว Mod 26 การบวก 26 ก่อนช่วยให้ค่าที่ส่งเข้า Mod ไม่ติดลบสำหรับคีย์ในช่วงที่อนุญาต ตัวที่ไม่ใช่ A–Z เช่นเว้นวรรคและเครื่องหมายตกใจผ่านไปโดยไม่เปลี่ยน วง For key = 0 To 25 เรียกฟังก์ชันเดิมครบทุกค่า จึงไม่มีช่องว่างในการค้นหา

อย่าสรุปว่าโปรแกรม “รู้” คำตอบเพียงเพราะคีย์ 3 อ่านได้ เราเป็นผู้ใช้ความหมายของภาษาเลือกบรรทัดนั้น ข้อความสั้นมากอาจมีหลายบรรทัดที่ดูเหมือนคำจริง ข้อความภาษาอื่นหรือข้อความที่ถูกเปลี่ยนด้วยอัลกอริทึมอื่นก็อาจไม่มีคำตอบที่อ่านรู้เรื่องเลย นอกจากนี้การลองครบ 26 คีย์ทำได้เพราะพื้นที่คีย์เล็ก ไม่ได้แปลว่าการไล่คีย์ทุกระบบเข้ารหัสเป็นวิธีที่เป็นไปได้
