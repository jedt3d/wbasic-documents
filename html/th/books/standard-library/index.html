ไลบรารีมาตรฐาน

โมดูล ชนิดข้อมูล และ procedure มาตรฐานที่โปรแกรม WBasic เรียกใช้ได้

ส่วนนี้จะจัดเอกสารตามโมดูล โดยบอก signature, ผลลัพธ์, error และตัวอย่างสั้นที่ ทดสอบกับ compiler รุ่นเดียวกับคู่มือ เนื้อหาปัจจุบันครอบคลุม API ที่ผ่านการ ตรวจสอบใน R5 บน Windows 11 ARM64 และ macOS ARM64 แล้ว

คำว่า “ผ่าน” ในเล่มนี้จึงหมายถึงผ่านบนสอง host และ revision ที่บันทึกไว้ ไม่ได้ขยาย เป็นคำรับรอง Linux ARM64 หรือ native x86_64 และไม่ได้แทน gate การแจกจ่ายแบบไม่มี SDK ของ R8

หน้าที่ยังวางแผนอยู่จะไม่ถูกเขียนให้ดูเหมือนเป็น API ที่พร้อมใช้—เพราะคู่มือ อ้างอิงควรช่วยลดเรื่องประหลาดใจ ไม่ใช่เป็นคนสร้างเรื่องประหลาดใจเสียเอง
