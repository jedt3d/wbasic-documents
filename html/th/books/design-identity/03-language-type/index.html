Design and Identity ของ WBasic

ฟอนต์ของภาษา

IBM Plex สำหรับการอ่าน ภาษาไทย และโค้ด พร้อมลำดับชั้นที่ใช้งานได้จริง

WBasic ใช้ IBM Plex Sans สำหรับ branding, heading, เนื้อหาภาษาอังกฤษ และ UI ใช้ IBM Plex Sans Thai กับ heading และ UI ภาษาไทย ส่วนข้อความภาษาไทยที่อ่านต่อเนื่อง ใน paragraph ใช้ IBM Plex Sans Thai Looped เพื่อให้รูปอักษรคุ้นตาและแยกพยัญชนะ ได้สบายขึ้น IBM Plex Mono ยังรับหน้าที่ code, identifier, path, terminal output และ keyboard shortcut ตระกูลเหล่านี้มีน้ำเสียงร่วมกัน จึงสลับจากคำอธิบายไปหาโค้ดได้ โดยไม่เหมือนเดินข้ามไปอีกเว็บไซต์

ลำดับชั้นก่อนขนาดตัวอักษร

Wordmark และ heading ใช้ Sans 600 เนื้อหาอ่านยาวใช้ 400 control ใช้ 500 และ 700 สงวนไว้สำหรับ emphasis ที่ต้องแข็งแรงจริง ๆ Code ใช้ Mono 400; 500 ใช้เมื่อจำเป็น ต้องชี้จุด ไม่ทำให้ทุก token ตะโกนแข่งกัน

Body อยู่ที่ 18px กับ line-height 1.65 และจำกัดความกว้างราว 68 ตัวอักษร Lead อยู่ที่ 22px/1.5 และไม่ยาวเกิน 55 ตัวอักษร การเลือกนี้ช่วยทั้งภาษาไทยที่มีสระและ วรรณยุกต์หลายระดับ กับภาษาอังกฤษที่ต้องการจังหวะบรรทัดสม่ำเสมอ Browser ยังปรับ zoom ได้ตามปกติ เพราะการอ่านไม่ควรมีข้อสอบสายตาก่อนเข้าสู่บทเรียน

กฎ Looped ใช้เฉพาะอักขระใน Unicode Thai block (U+0E00–U+0E7F) ภายใน lead และ paragraph ส่วนอักษรละติน เลขอารบิก และเครื่องหมายที่อยู่นอกช่วงนี้ยังใช้ IBM Plex Sans ด้วย unicode-range ส่วน heading, navigation, button, table และ code ไม่เปลี่ยนตามกฎนี้

โค้ดต้องตรงกว่าความสวย

Mono รักษา whitespace และ punctuation ตาม source จริง ไม่เปลี่ยน case ไม่บีบ tracking และไม่ลดขนาดเพื่อยัดบรรทัดยาว ให้เลื่อนแนวนอนแทน ข้อความ comment ใช้ ฟอนต์ italic จากไฟล์จริง ไม่สั่ง browser เอียงฟอนต์ขึ้นเอง และไม่สร้าง bold-italic สังเคราะห์เมื่อไม่ได้จัดไฟล์นั้นมาให้

ฟอนต์ของเว็บไซต์ถูกเก็บใน repository พร้อม SIL Open Font License ส่วนฟอนต์ใน terminal เป็นการตัดสินใจของผู้ใช้และ terminal host จึงต้องตรวจ Thai shaping, cell width และ fallback แยกต่างหาก TlwgMono หรือ Nerd Font อาจเหมาะกับ terminal บางชุด แต่ไม่ได้แทนระบบตัวอักษรของเว็บไซต์โดยอัตโนมัติ—เสื้อทำงานกับชุดออกงาน อยู่ตู้เดียวกันได้ โดยไม่ต้องเป็นตัวเดียวกัน
