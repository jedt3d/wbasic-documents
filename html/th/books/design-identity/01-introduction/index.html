Design and Identity ของ WBasic

เกริ่นนำ: บุคลิกของ WBasic

จาก Tungsten BASIC สู่ภาษาที่สงบ แม่นยำ เป็นมิตร และพร้อมเติบโต

WBasic มีชื่อเต็มในแนวคิดว่า Tungsten BASIC ชื่อนี้ช่วยตั้งเข็มทิศให้การออกแบบ: แข็งแรงโดยไม่ต้องส่งเสียงดัง แม่นยำพอสำหรับงานจริง และไม่ปิดประตูใส่สิ่งที่จะ เกิดขึ้นในอนาคต ภาพลักษณ์จึงไม่พยายามย้อนยุคไปเป็นหน้าจอคอมพิวเตอร์สีเขียว และไม่แต่งตัวเป็นผลิตภัณฑ์องค์กรจนผู้เริ่มต้นไม่กล้าแตะ

Wbasic.
สงบพื้นผิวเงียบ ให้เนื้อหาเป็นพระเอก
พึ่งพาได้ลำดับชัด contrast สูง และใช้ซ้ำได้
เข้าถึงง่ายเป็นมิตรกับมือใหม่โดยไม่ลดความแม่นยำ
พร้อมเติบโตกติกาแข็งแรงพอให้หน้าตาใหม่อยู่ร่วมกันได้

ภาษากับหน้าตาต้องพูดเรื่องเดียวกัน

ตัวภาษาเลือกคำอย่าง Procedure, Let และ Structure ให้ความหมายมองเห็นได้ ระบบภาพก็ใช้หลักเดียวกัน: heading ต้องบอกลำดับ, link ต้องดูออกว่าไปที่อื่น, code ต้องรักษาอักขระทุกตัว และสถานะสำคัญต้องมีคำอธิบาย ไม่ฝากความหวังไว้กับ สีเพียงอย่างเดียว

คำว่า WBasic เป็นชื่อภาษา ส่วน wordmark ใช้รูป Wbasic. เพื่อให้จังหวะคำ สงบและมีจุด teal เป็นลายเซ็นเล็ก ๆ จุดนั้นมีหน้าที่สร้างการจดจำ ไม่ได้รับงานหนัก อย่างการเป็นปุ่ม ไฟจราจร และเครื่องหมายตกใจพร้อมกัน

เอกลักษณ์ที่ไม่แย่งเนื้อหา

พื้น Mist เปิดพื้นที่ให้อ่าน ตัวอักษร Charcoal ให้ contrast สูง ส่วน Teal, Sage และ Sand เข้ามาเมื่อมีเหตุผล รูปทรงใช้มุมโค้งเพียงเล็กน้อยและเว้นช่องไฟตามจังหวะ 4, 8, 16, 24, 32 และ 48 พิกเซล ผลที่ต้องการคือหน้าอ้างอิงที่อยู่ด้วยได้นาน: ดูมีบุคลิกเมื่อมองทั้งหน้า และยอมถอยเมื่อผู้อ่านกำลังแกะ error ยาก ๆ

เอกลักษณ์จึงไม่ใช่ของประดับที่แปะหลังงานเสร็จ แต่เป็นกติกาชุดเล็กที่ช่วยให้ คนหลายคนตัดสินใจไปในทิศเดียวกัน—และช่วยลดการประชุมเรื่อง “เขียวนี้เขียวพอไหม” ได้อย่างน่าพอใจ
