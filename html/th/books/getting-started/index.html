Getting Started

เริ่มใช้ WBasic ผ่าน Billing Time ตั้งแต่เครื่องมือ โครงสร้างโครงการ ภาษา และการ compile บน command line

หนังสือเล่มนี้พาเริ่ม WBasic ผ่าน Billing Time โปรแกรมบรรทัดคำสั่งขนาดเล็กสำหรับ รวมเวลาทำงานและคำนวณยอดก่อนวางบิล สี่บทแรกเป็นเส้นทางที่รันได้จริง: รู้จักเครื่องมือ สร้างโครงการ อ่านภาษา แล้วตรวจ compile และรันจาก command line

บทที่ 5–9 พาตัวอย่างเดียวกันไปสู่ model, SQLite และ transaction ด้วย WORM ซึ่งยังเป็น ข้อเสนอ เนื้อหาช่วงนั้นจึงติดป้าย Planned ไว้ตรง ๆ เพื่อไม่เอาความหวังไปปลอมเป็น binary

เริ่มที่ รู้จักเครื่องมือและ compiler

01 1 · รู้จักเครื่องมือและ compiler สำรวจ wb, ตรวจรุ่น และเข้าใจว่า compiler ทำอะไรให้โครงการ Billing Time 02 2 · สร้างโครงการ Billing Time วาง manifest, source tree และโปรแกรมแรกที่ compiler ปัจจุบันตรวจและรันได้ 03 3 · เดินชมภาษาใน Billing Time อ่าน Procedure, Let, type, control flow, command-line arguments และ standard output 04 4 · ตรวจ Compile และรันจาก command line ใช้ project-info, check, run และ emit-object กับโครงการที่สร้างจริง 05 5 · ออกแบบ model หก Structure ความสัมพันธ์ และเหตุผลที่ database record ยังเป็น value ธรรมดา 06 6 · Schema และข้อมูลเริ่มต้น เปิด SQLite อย่างมีขอบเขต ใช้ migration ชัดเจน และสร้างข้อมูลตั้งต้นแบบ typed 07 7 · บันทึกเวลาและราคา เก็บ rate snapshot และคำนวณยอดด้วย integer arithmetic ที่ตรวจสอบเหตุผลได้ 08 8 · สร้าง invoice ใน transaction เลือกเวลาที่ยังไม่วางบิล สร้าง line และเปลี่ยนสถานะอย่างเป็นอะตอม 09 9 · ทดสอบและไปต่อ ผลลัพธ์ที่คาดหวัง acceptance cases และเส้นแบ่งก่อนเรียกตัวอย่างว่ารันได้
