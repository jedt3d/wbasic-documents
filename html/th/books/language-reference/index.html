คู่มือภาษา

ไวยากรณ์และความหมายของโปรแกรม WBasic

หนังสือนี้อธิบายภาษา WBasic โดยเริ่มจากโปรแกรมที่รันได้ แล้วจึงวางกฎของ ข้อความต้นฉบับและระบบชนิด ก่อนต่อไปยังนิพจน์ การควบคุมลำดับงาน โพรซีเยอร์ ค่า โมดูล และข้อผิดพลาด

คำว่า “เขียนแล้ว” หมายถึงบทอ้างอิงครอบคลุมเฉพาะพฤติกรรมที่ implementation ปัจจุบันมีหลักฐานทดสอบผ่าน ไม่ได้หมายความว่าข้อเสนอทุกข้อใน specification draft พร้อมใช้แล้ว ความสามารถที่ยัง Planned หรือ Deferred จะไม่ถูกยกเป็นสัญญาของภาษาในหนังสือ

สถานะหลักฐาน ณ จุดตรวจนี้คือ 71 Passed, 23 Planned และ 1 Deferred ใน behavior catalog การทดสอบ native ครอบคลุม Windows 11 ARM64 และ macOS ARM64 ตาม environment ที่บันทึกไว้ ส่วน Linux ARM64 และ native x86_64 ยังไม่มี acceptance matrix ครบถ้วน การสร้างชุดแจกจ่ายบนเครื่องสะอาดที่ไม่มี SDK เป็น gate ของ R8 และยังไม่ใช่ความสามารถ ที่หนังสือเล่มนี้รับรอง

01 โปรแกรม WBasic หนึ่งโปรแกรม โปรแกรมที่สมบูรณ์และเล็กที่สุด รูปแบบ entry point และคำสั่งสำหรับตรวจและรัน 02 ข้อความต้นฉบับ ชื่อ literal และการจัดบรรทัด วิธีที่ WBasic อ่าน UTF-8, identifier, comment, ตัวเลข, string และ logical line 03 ชนิดข้อมูล declaration และการแปลงค่า ชนิดพื้นฐาน local value, constant, nullability และการแปลงตัวเลขแบบชัดเจน 04 นิพจน์ ตัวดำเนินการ และความเท่ากัน ลำดับการคำนวณ arithmetic, Boolean, nullable fallback และ value equality 05 การควบคุมลำดับงาน If, Select, While, For, For Each และการออกจากลูปอย่างชัดเจน 06 Procedure และ parameter การประกาศ การเรียก optional/named argument, ByRef และ procedure value 07 Structure และ value semantics Named records, defaults, attached procedures และการคัดลอกค่าที่ไม่สร้าง alias แฝง 08 Null safety Non-null by default, nullable types, If Let, safe call และ lazy fallback 09 Collection และข้อความ Unicode Array, Map, indexing, slicing, value semantics และกฎของ String 10 Error และอายุของ resource Try/Catch/Finally, Error model, Using, cleanup order และ suppressed errors 11 Enum และ Flags ชนิดค่าที่มีชื่อ ชุด bit flags และข้อจำกัดการแปลงค่า 12 Module, package และ visibility โครงสร้าง .wproj/.wmod, namespace, Import และขอบเขต Public/Internal/Private 13 Entry point, เครื่องมือ และ diagnostics Main ที่รองรับ คำสั่งพัฒนาที่มีอยู่ และสัญญารายงานข้อผิดพลาด
