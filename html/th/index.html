โครงคู่มือสำหรับพฤติกรรม WBasic v0.3 ที่ตรวจสอบแล้ว

คู่มืออ้างอิง WBasic

รวมกฎภาษา ไลบรารีมาตรฐาน และ API สาธารณะไว้ในคู่มือที่ผูกกับเวอร์ชัน

อ่านแยกตามหนังสือ

คู่มือนี้แยกกฎของภาษาออกจากไลบรารีมาตรฐานและ API ของโมดูล ทุกหน้าอธิบาย พฤติกรรมที่ผ่านการตรวจสอบในขอบเขต WBasic v0.3 แล้ว ส่วนข้อเสนอที่ยังไม่ได้ พัฒนาจะอยู่ในเอกสารนักพัฒนาจนกว่าจะมีหลักฐานการทำงาน

ขอบเขตรุ่นปัจจุบัน

ฉบับภาษาไทยครอบคลุมตัวภาษา ไลบรารีมาตรฐาน และ API สาธารณะที่ตรวจสอบแล้วถึง implementation ปัจจุบัน แต่ละบทมีกฎที่ชัดเจน ตัวอย่างขนาดเล็ก กรณีขอบ และ diagnostics ที่เกี่ยวข้อง ความสามารถที่ยัง Planned หรือ Deferred จะถูกบอกตามจริง แทนการเร่งเขียนให้ดูเหมือนพร้อม—หนังสืออ้างอิงไม่ควรแต่งนิยายแทน compiler

ภาษาไทยเป็นต้นฉบับหลักในรอบนี้ ส่วนฉบับภาษาอังกฤษจะเริ่มเมื่อฉบับนี้ผ่านการตรวจ โดยบรรณาธิการเทคนิคและได้รับคำสั่งให้แปล

ข้อตกลงการเขียน

Keyword และชื่อ API แสดงตรงตามที่ compiler รับ โปรแกรมที่สมบูรณ์มี Main หนึ่งตัว ส่วนตัวอย่างที่เป็น fragment จะระบุบริบท ชนิด ค่า และ error ใช้ชื่อ ของ WBasic โดยตรง ไม่อาศัยความหมายจากภาษาอื่น

01 คู่มือภาษา ไวยากรณ์และความหมายของโปรแกรม WBasic เปิดหนังสือ 02 ไลบรารีมาตรฐาน โมดูล ชนิดข้อมูล และ procedure มาตรฐานที่โปรแกรม WBasic เรียกใช้ได้ เปิดหนังสือ 03 คู่มือ API signature และสัญญาการทำงานของ API สาธารณะ แยกตาม module เปิดหนังสือ 04 Design and Identity ของ WBasic แนวคิด สี และตัวอักษรที่ทำให้ WBasic มีบุคลิกเดียวกันทั้งภาษาและเอกสาร เปิดหนังสือ 05 Tutorials เรียน WBasic ผ่านโครงการตัวอย่าง ตั้งแต่โครงไฟล์ไปจนถึงเหตุผลของโค้ดแต่ละส่วน เปิดหนังสือ
