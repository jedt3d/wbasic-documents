คู่มือสำหรับพฤติกรรม WBasic v0.3 ที่ตรวจสอบแล้ว

คู่มืออ้างอิง WBasic

รวมกฎภาษา ไลบรารีมาตรฐาน และ API สาธารณะไว้ในคู่มือที่ผูกกับเวอร์ชัน

อ่านแยกตามหนังสือ

คู่มือนี้แยกกฎของภาษาออกจากไลบรารีมาตรฐานและ API ของโมดูล ทุกหน้าอธิบาย พฤติกรรมที่ผ่านการตรวจสอบในขอบเขต WBasic v0.3 แล้ว ส่วนข้อเสนอที่ยังไม่ได้ พัฒนาจะอยู่ในเอกสารนักพัฒนาจนกว่าจะมีหลักฐานการทำงาน

ขอบเขตรุ่นปัจจุบัน

ฉบับภาษาไทยครอบคลุมตัวภาษา ไลบรารีมาตรฐาน และ API สาธารณะที่ตรวจสอบแล้วถึง implementation ปัจจุบัน แต่ละบทมีกฎที่ชัดเจน ตัวอย่างขนาดเล็ก กรณีขอบ และ diagnostics ที่เกี่ยวข้อง ความสามารถที่ยัง Planned หรือ Deferred จะถูกบอกตามจริง แทนการเร่งเขียนให้ดูเหมือนพร้อม—หนังสืออ้างอิงไม่ควรแต่งนิยายแทน compiler

ภาษาไทยเป็นต้นฉบับหลัก ฉบับภาษาอังกฤษแปลจากเนื้อหาที่ผ่านการตรวจ โดยบรรณาธิการเทคนิคแล้วตามคำสั่งของผู้ใช้ โดยรักษาขอบเขตและสถานะเดิม

ข้อตกลงการเขียน

Keyword และชื่อ API แสดงตรงตามที่ compiler รับ โปรแกรมที่สมบูรณ์มี Main หนึ่งตัว ส่วนตัวอย่างที่เป็น fragment จะระบุบริบท ชนิด ค่า และ error ใช้ชื่อ ของ WBasic โดยตรง ไม่อาศัยความหมายจากภาษาอื่น

01 Getting Started เริ่มใช้ WBasic ผ่าน Billing Time ตั้งแต่เครื่องมือ โครงสร้างโครงการ ภาษา และการ compile บน command line เปิดหนังสือ 02 Small Wbasic Projects ฝึกคิด เขียน และตรวจโปรแกรมขนาดเล็กด้วย WBasic — ฉบับภาษาไทย เปิดหนังสือ 03 คู่มือภาษา ไวยากรณ์และความหมายของโปรแกรม WBasic เปิดหนังสือ 04 ไลบรารีมาตรฐาน โมดูล ชนิดข้อมูล และ procedure มาตรฐานที่โปรแกรม WBasic เรียกใช้ได้ เปิดหนังสือ 05 คู่มือ API signature และสัญญาการทำงานของ API สาธารณะ แยกตาม module เปิดหนังสือ 06 Design and Identity ของ WBasic แนวคิด สี ตัวอักษร โลโก้ และมาสค็อตที่ทำให้ WBasic มีบุคลิกเดียวกันทั้งภาษาและเอกสาร เปิดหนังสือ
