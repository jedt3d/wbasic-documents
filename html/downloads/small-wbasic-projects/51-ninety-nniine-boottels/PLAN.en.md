# Project 51 Plan: Count Down Bottles with Altered Letter Cases

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Count Down Bottles with Altered Letter Cases.
Data: the bottle-counting text and letter-case patterns.
Method: Count down and vary letter case according to a fixed seed.
Acceptance check: Starting at 2 counts 2, 1, 0 in order.
Remaining gap: Specify the PRNG for case variation and verify Unicode casing.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
