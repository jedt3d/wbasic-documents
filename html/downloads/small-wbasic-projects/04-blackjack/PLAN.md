# แผนโครงการ 04: เล่นไพ่แต้มยี่สิบเอ็ดกับเจ้ามือ

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: เล่นไพ่แต้มยี่สิบเอ็ดกับเจ้ามือ
ข้อมูล: สำรับ 52 ใบและมือสองฝ่าย
ขั้นตอน: สับด้วย seed; Ace นับ 11 แล้วลดเป็น 1 เมื่อเกิน 21
เกณฑ์ตรวจ: A+9+5 ต้องนับ 15
ข้อจำกัด: ต้องตรวจ: ต้องสร้างชุดไพ่และการสับด้วย PRNG ที่พิสูจน์แล้ว; ยังไม่มี public API สำหรับการสุ่ม

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
