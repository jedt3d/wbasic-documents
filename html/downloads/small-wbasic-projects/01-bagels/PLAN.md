# แผนโครงการ 01: เกมเดารหัสสามหลักจากคำใบ้ตำแหน่งตัวเลข

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: เกมเดารหัสสามหลักจากคำใบ้ตำแหน่งตัวเลข
ข้อมูล: รหัสสามหลักไม่ซ้ำและคำใบ้
ขั้นตอน: สับ 0–9 ด้วย seed แล้วเทียบตำแหน่งเลข
เกณฑ์ตรวจ: รหัส 248 เดา 843 ได้ตรงหนึ่ง ผิดตำแหน่งหนึ่ง
ข้อจำกัด: ต้องตรวจ: ต้องเขียนตัวสุ่มแบบ seed คงที่ในบทและตรวจช่วงจำนวนเต็ม; ยังไม่มี public API สำหรับการสุ่ม

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
