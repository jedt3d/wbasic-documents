# Project 05 Plan: Bounce a Logo and Count Corner Hits

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Bounce a Logo and Count Corner Hits.
Data: the logo coordinates, travel direction, and screen dimensions.
Method: Advance the logo on each tick and reverse direction when it reaches an edge.
Acceptance check: After hitting the right edge, horizontal direction dx is negative.
Remaining gap: Verify the TUI timer, viewport dimensions, and repeated rendering on a real terminal.
