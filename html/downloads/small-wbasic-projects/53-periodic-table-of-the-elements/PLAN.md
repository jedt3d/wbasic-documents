# แผนโครงการ 53: ค้นข้อมูลธาตุจากตาราง

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: ค้นข้อมูลธาตุจากตาราง
ข้อมูล: ตารางเลขอะตอม สัญลักษณ์ ชื่อ
ขั้นตอน: อ่านชุดข้อมูลที่ตรวจที่มาแล้วค้นสองคีย์
เกณฑ์ตรวจ: เลข 1 ได้ H; เลข 0 ไม่พบ
ข้อจำกัด: ต้องตรวจ: ต้องเตรียมชุดข้อมูลธาตุที่มีสิทธิ์ใช้และตรวจการอ่านไฟล์/ฝังข้อมูล

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
