# แผนโครงการ 02: จำลองโอกาสคนเกิดวันเดียวกันในกลุ่ม

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: จำลองโอกาสคนเกิดวันเดียวกันในกลุ่ม
ข้อมูล: จำนวนคน วันเกิด 1–365 และรอบทดลอง
ขั้นตอน: สร้างวันเกิดจาก seed แล้วนับกลุ่มที่มีวันซ้ำ
เกณฑ์ตรวจ: กลุ่มหนึ่งคนต้องชน 0 ครั้ง
ข้อจำกัด: ต้องตรวจ: ต้องกำหนดวันเกิดจำลองด้วย PRNG ที่ตรวจแล้ว; ยังไม่มี public API สำหรับการสุ่ม

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
