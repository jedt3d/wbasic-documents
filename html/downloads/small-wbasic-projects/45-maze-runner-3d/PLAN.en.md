# Project 45 Plan: Render a Text-Based First-Person Maze

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Render a Text-Based First-Person Maze.
Data: the maze map, facing direction, and view.
Method: Project front and side walls into a text drawing, then handle turns and forward movement.
Acceptance check: Four right turns return the player to the original facing direction.
Remaining gap: Verify view rendering and TUI key input on a real terminal.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
