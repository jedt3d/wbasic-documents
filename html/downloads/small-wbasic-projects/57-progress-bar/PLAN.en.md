# Project 57 Plan: Show Task Progress as a Bar

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Show Task Progress as a Bar.
Data: total work, completed work, and bar width.
Method: Compute the number of filled cells and redraw when progress changes.
Acceptance check: At 5 of 10 tasks with width 10, five cells are filled.
Remaining gap: A static percentage bar is feasible; live updates require verification of the TUI timer.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
