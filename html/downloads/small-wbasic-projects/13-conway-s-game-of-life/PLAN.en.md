# Project 13 Plan: Evolve Conway's Game of Life

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Evolve Conway's Game of Life.
Data: two generations of Boolean grid cells.
Method: Count each cell's eight neighbors in the old generation, then update all cells together.
Acceptance check: A horizontal line of three live cells becomes a vertical line of three.
Remaining gap: Array logic can implement the cell rules; live play still requires verification of TUI timer and key events.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
