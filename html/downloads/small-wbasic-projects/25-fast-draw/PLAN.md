# แผนโครงการ 25: แข่งกดปุ่มเมื่อสัญญาณปรากฏ

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แข่งกดปุ่มเมื่อสัญญาณปรากฏ
ข้อมูล: สถานะสัญญาณและ elapsedMs
ขั้นตอน: รอ timer; กดก่อนเป็น false start; หลังเป็นเวลาตอบ
เกณฑ์ตรวจ: กดก่อนสัญญาณต้องไม่ถูกนับว่าชนะ
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ TUI timer, timestamp/elapsed ของ event และอินพุตจริง
