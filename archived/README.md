# หนังสือ WBasic — ต้นฉบับที่กำลังเขียน

สองเล่มนี้เริ่มจากหลักฐาน R1–R4 ตามดัชนีด้านล่าง R5 developer milestone ผ่าน native Windows/macOS ARM64 แล้ว: stream/text, dynamic `Json.Value`, generated codecs, Http loopback, Sqlite/Csv และ nested matcher/aggregate ดู [หลักฐาน R5](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/evidence/r5-complete-2026-09-28.json) และ [round report](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/rounds/R5-streams-data-libraries.md) บท R6 เพิ่ม typed TUI/Jobs foundation พร้อม [ตัวอย่าง fake clock และ worker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r6/README.md) บท R7 groups 1–6 มี automated evidence แยกจาก visual font inspection; บท 11 ของทั้งสองเล่มเริ่ม capstone SQLite showcase/acceptance และยัง Draft จนกว่า matched native gates ของ groups 7–8 จะผ่าน Clean-machine no-SDK อยู่ R8, Linux/x86_64 ยังไม่มี native endpoint
