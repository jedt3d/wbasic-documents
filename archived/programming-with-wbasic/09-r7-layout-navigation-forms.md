# 9. R7 Layout, navigation และ forms

**R7 groups 1–3: selected layout, navigation และ forms behavior verified บน Windows/macOS ARM64 ที่ `572b68b`.** บทเรียนทั้งสามผ่าน matched native exact-output; source fixtures, real-terminal gates, Rust tests, tooling และ books ผ่านที่ SHA เดียวกัน ผลนี้ไม่ใช่การปิด R7 ทั้งหมด ขอบเขตตาม [R7 ordered plan](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/rounds/R7-ordered-plan.md) และ [normative TUI spec](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/wbasic-tui-spec-draft-0.3.md) ข้อค้าง [R6-D1–D5](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/rounds/R6-deferred-verification.md) ยังคงเป็น release blockers

## 1. Layout และ appearance — selected behavior verified

บทเรียนแรกจะสร้าง view ที่มี Row/Column, Panel และ ScrollViewport โดยกำหนดขนาดแบบ Auto, Cells และ Percent พร้อม min/max, Grow/Shrink, padding/margin/gap, wrap, alignment และ overflow การ resize ต้องรักษา stable control IDs และ state เมื่อพื้นที่เล็กกว่าขนาดขั้นต่ำ layout ต้อง clip หรือ scroll ตาม policy โดยไม่มีขนาดติดลบ การแบ่งเศษเซลล์ให้ตรวจด้วยลำดับ declaration ตามสเปก §5.1

Theme lesson จะเปรียบ Dark, Light, HighContrast และ custom tokens บน capability profiles truecolor, 256, 16 และ monochrome สี fallback ต้อง deterministic และข้อความสถานะยังแยกได้โดยไม่พึ่งสี `NO_COLOR` มีผลเมื่อใช้ Auto; การเลือก explicit ไม่ทำให้ non-TTY พิมพ์ escape เอง ส่วน Thai/emoji grapheme, clipping และ border เป็นข้อทดสอบเซลล์ตั้งแต่กลุ่มนี้ แต่ visual font matrix จริงอยู่กลุ่ม 6

[layout-theme-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/layout-theme-headless.wbas) ผ่าน matched native Windows/macOS ARM64 ที่ source `2e3d47c` และผ่านอีกครั้งใน integrated gate `572b68b` ตัวอย่างให้ `A` กว้างสามเซลล์ก่อน `B`, สร้าง style ใหม่ด้วย `WithForeground` จาก base style และกำหนด Accent ผ่าน Dark theme แล้วอ่าน `SnapshotCells().Style` เพื่อเทียบเซลล์หลัง layout การ `Resize(12, 1)` เก็บ model/style เดิม; `original.WithLayout(...)` ให้ view ที่ clip เหลือ `ori` โดย node เดิมยัง render เป็น `original` Checker ยืนยัน stdout exact `A  B`, `True`, `True`, `A  B`, `ori`, `original` ทีละบรรทัด ทั้งสอง host ผ่าน source cases และ real terminal RGB/Unicode border กับ input/output restoration ข้อจำกัดที่เหลือคือ actual font matrix และ profile/host combinations ที่ยังไม่มี native endpoint

## 2. Navigation และ dialogs — selected behavior verified

บทเรียนถัดไปจะให้ keyboard-only path ผ่าน Button, Tabs, Menu/CommandPalette, help/keymap, SplitPane และ Modal/Dialog โดยเชื่อมการ match key กับข้อความ help จาก binding ชุดเดียวกัน Focus traversal เรียง TabIndex แล้ว tree order; disabled/hidden/removed nodes ไม่รับ focus Modal trap Tab, ปิดแล้วคืน prior focus เมื่อยัง eligible; Escape เป็น event ให้อัปเดต model ไม่ใช่ renderer ปิดเอง Mouse hit-test ต้องเคารพ clip, scroll และ topmost visible node; wheel ส่งต่อ parent เมื่อ nested scroller ถึงขอบ Inline modal ต้องบอกข้อจำกัดอย่างชัดเจน

[navigation-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/navigation-headless.wbas) ใช้ `Tui.KeyBinding.Create` ชุดเดียวกันสำหรับ `Matches` และ `Tui.Help` จากนั้น fake session คลิก Stack ที่ซ้อน Button สองตัวเพื่อดูว่าตัวบนรับ Activate เลือกแท็บโดยให้แอปอัปเดต `ActiveTab` เอง และรับ `SplitEvent.ProposedFirstCells` โดยยังเก็บ `SplitCells` เดิมจนแอปยอมรับค่าใหม่ [checker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/run-navigation-lesson.mjs) ผ่าน exact stdout บน Windows/macOS ARM64 ที่ `572b68b` Full navigation fixture ที่ SHA เดียวกันตรวจ modal trap/restore, shared focus group, topmost routing และ Inline limitation เพิ่มจากบทเรียนสั้น

## 3. Text entry และ forms — selected behavior verified

บทเรียน forms จะใช้ TextInput, PasswordInput และ TextArea กับ Label, Checkbox, RadioGroup, Select/MultiSelect และ validation summary ตาม public API ที่ลงตัว การแก้ text เป็น typed state transition: callback นำ state ใหม่กลับใส่ model, ใช้ consumed result ก่อน global shortcuts, และส่ง WidgetActions ผ่าน context effect ที่อนุญาต การพิมพ์ `q` ใน editor จึงไม่ Quit; paste เป็น undo transaction เดียว Caret, selection และ delete เดินตาม grapheme ไม่ตัด Thai mark หรือ emoji ระหว่าง cluster PasswordInput ต้อง mask ทั้ง frame และ public snapshot; clipboard เป็น explicit action ภายใต้ route/policy ของ R6 ไม่ใช่การอ่าน clipboard อัตโนมัติ

[forms-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/forms-headless.wbas) ผ่าน matched native exact stdout บนทั้งสอง ARM64 hosts ที่ `572b68b`: เตรียม opaque states ใน model ก่อน `Tui.Test.Create`, จากนั้น Init ตั้ง text และ focus `name` Update รับเฉพาะ `TargetId="name"` แล้วให้ editor consume key `q` ก่อน app shortcut; Backspace ลบ `q` และ emoji ทั้ง grapheme จนเหลือ `ก้` ที่ caret 1 View มี label, PasswordInput ที่ mask `secret` และ validation summary Ctrl+V คืนหนึ่ง `RequestedActions` แต่ตัวอย่างไม่ `Apply` จึงไม่มี pending clipboard effect แอปจริงต้องตรวจ action และเรียก `context.Apply(...)` ภายใต้นโยบายที่กำหนดก่อนจะมี I/O [checker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/run-forms-lesson.mjs) ตรวจ stdout และไม่ให้ `secret` ปรากฏใน public snapshot; source fixtures ครอบคลุม form values/terminal เพิ่มจากบทเรียน

[ตัวอย่าง R7](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/README.md) ทั้งสามรันได้ด้วย matched compiler/runtime ที่ `572b68b` หลักฐานรวมมีหก headless native cases, สอง real-terminal cases และสามบทเรียน exact stdout บนทั้งสอง hosts พร้อม Windows 394/Mac 386 Rust tests, strict Clippy/format, protocol 40 และ editor 48 tests ไม่มี skip การทดสอบ actual font matrix และข้อค้าง Windows clipboard ยังแยกจากผล fake session; กลุ่ม 4–8 และ no-SDK packaging อยู่นอกบทนี้
