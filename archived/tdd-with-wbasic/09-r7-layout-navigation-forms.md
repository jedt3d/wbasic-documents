## Group 1: layout และ theme

Given viewport ที่มี fixed, auto, percent และ weighted children; When resize ผ่านขนาด 0, tiny และ normal; Then cell bounds ไม่ติดลบ, min/max และ largest-remainder rounding ตรงสเปก, clipping ไม่ทิ้ง ghost cells และ stable IDs/state ไม่หาย (T05/T12) ทดสอบ wrap, padding/gap, nested scroll และ ensure-visible ด้วย exact cell/tree snapshot แยก profile ของ Thai/emoji จาก actual font rendering

Given source RGB/theme tokens และ capability profiles truecolor, 256, 16, monochrome พร้อม `NO_COLOR`; When render สถานะ focused/disabled/selected; Then fallback สี deterministic และความหมายยังอ่านออกโดยไม่พึ่งสี (T16) ข้อผิดพลาด negative/NaN/Infinity/min>max ต้องเป็น Validation ที่ชัด ไม่ใช่ frame ว่างหรือ crash

[layout-theme-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/layout-theme-headless.wbas) เป็น Red/Green ขั้นแรก: Given base style, derived Accent style และ `A` ที่มี Cells(3); When สร้าง fake session, ดู cell 0/3, resize จาก 8×1 เป็น 12×1 และ render immutable original/clipped nodes; Then checker ยืนยัน `A  B\nTrue\nTrue\nA  B\nori\noriginal\n` แบบ exact บน native Windows/macOS ARM64 ที่ source `2e3d47c` และ integrated gate `572b68b` พร้อม source cases และ real terminal RGB/Unicode border กับ restoration ข้อจำกัดที่ยังต้องตรวจแยกคือ actual Thai font matrix และ profile/host combinations ที่ไม่มี native endpoint

## Group 2: focus, routing และ modal

Given controls ที่มี TabIndex, disabled/hidden sibling และ nested scroll; When Tab/Shift+Tab, mouse click/drag/wheel, removal และ resize; Then TargetId, focus order, hit-test และ capture release ตรง committed layout (T09/T10) เมื่อ modal เปิดต้อง trap focus และบล็อก background; เมื่อปิดคืน prior focus เฉพาะถ้ายัง eligible Escape ให้ app ตัดสินใจปิด และ Activate หนึ่งครั้งต่อ action ไม่มี callback re-entry การทดสอบ Inline modal ต้องตรวจ limitation ที่ public API รายงาน (T27)

[navigation-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/navigation-headless.wbas) ผ่าน Red/Green matched native บนทั้งสอง hosts ที่ `572b68b`: Given Stack ที่มี `bottom`/`top`, tabs ที่ `ActiveTab=tab-a`, binding `ctrl+k` และ split ที่ `SplitCells=3`; When คลิก Stack, เปลี่ยน mode, คลิกแท็บ `tab-b` และกด Right บน split; Then [checker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/run-navigation-lesson.mjs) ยืนยัน `binding:True`, `stack:1:0`, `active-before:tab-a`, `help:True`, `active-after:tab-b:True`, `split:3:4` แบบ exact ค่า 4 เป็น proposal ไม่ใช่การแก้ model โดย renderer Full navigation fixture ตรวจ modal trap/restore, shared focus group, topmost routing และ Inline limitation เพิ่มจากบทเรียน

## Group 3: editing และ forms

Given TextInput ที่ focus; When committed `q` กับ paste ไทย/emoji; Then text update ถูก consume ก่อน global `q` shortcut, paste ทำ undo หนึ่งครั้ง, caret/selection/delete ไม่แยก grapheme (T06/T11/T37) Given PasswordInput; When snapshot cells/tree; Then plaintext ไม่ปรากฏใน public snapshot (T33) Given disabled/read-only field และ invalid form; When submit; Then value ไม่เปลี่ยนตาม policy และ validation summary มีข้อความที่อ่านได้โดยไม่อาศัยสี (T13/T16) Clipboard action ต้องตรวจ request/completion/error ภายใต้ route ที่เลือกโดยไม่แตะ clipboard ผู้ใช้จริง

[forms-headless.wbas](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/forms-headless.wbas) ผ่าน Red/Green matched native บนทั้งสอง hosts ที่ `572b68b`: Given initial model มี opaque states ก่อน initial view, Init focus `name` และ View แสดง label/editor/password/validation; When ส่ง key `q`, Backspace สองครั้งและ Ctrl+V ผ่าน fake session; Then `q` เพิ่มใน TextInput แต่ `QuitCount=0`, text เหลือ `ก้` กับ caret 1, `RequestedActions.Length=1` แต่ `PendingClipboard().Length=0` เพราะแอปไม่ Apply และ snapshot ต้องมี `! Name is required` กับ bullet หกตัวโดยไม่มี `secret` [checker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7/run-forms-lesson.mjs) ยืนยัน stdout exact `text:ก้👩‍💻q\nquit:0\ngrapheme:ก้\ncaret:1\nrequested:1\napplied:0\nName\nก้\n! Name is required\n••••••\n! name: Name is required\n` Source/native form fixtures ตรวจ values และ terminal เพิ่ม; test นี้ไม่แตะ OS clipboard จริง

Red ที่ต้องยอมรับคือ assertion ของ state/cell/error code ที่ระบุไว้; timeout, crash, missing test และ zero discovered tests เป็น failure คนละชนิด Integrated gate `572b68b` ผ่านหก headless native cases, สอง real-terminal cases, สามบทเรียน exact stdout, Windows 394/Mac 386 Rust tests, strict Clippy/format, protocol 40 และ editor 48 tests ไม่มี skip กลุ่ม 4–8, actual font matrix, R6 blockers และ R8 no-SDK gate แยกออกจากบทนี้
