The [book checker](https://github.com/jedt3d/wbasic-language/blob/main/examples/r7-data/run-lessons.mjs) passed 6/6 source and 6/6 exact native cases on each host; protocol passed 41/41 and editor 51/51 with no skips on each host. Three terminal cases (new data-rich plus existing style/forms) and doctor passed on both hosts. The release paint-only trace was 686 ms on Windows and 296 ms on Mac for 3,000 table paints; it does not measure application callbacks, I/O or transport. The API bindings are in [frontend_r7_data_rich.rs](https://github.com/jedt3d/wbasic-language/blob/main/crates/wb-compiler/src/frontend_r7_data_rich.rs) with feature flags `r7-tui-data`, `r7-tui-rich`, `r7-tui-text-metrics`. A page is bounded to 4,096 rows and 8 MiB; a global TreeIndex to 100,000 nodes. List/Table `Total` may be larger because only a page is resident. Canvas is a local mutable resource; its immutable Node snapshot may be retained in the UI model after Close, but `Tui.Node` is not worker-transferable. The doctor separates detected information from manual font metadata and an observer's visual result; non-interactive visual status stays Unknown.
