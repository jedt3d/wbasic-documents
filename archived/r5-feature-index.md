# Feature parity — R5 streams, JSON and data libraries

R5 is verified within its developer scope on native Windows and macOS ARM64. Core code was checked at `dc2a45e`; a harness-only timeout-fixture change at `461285c` had affected tests rerun on Windows and the remaining Mac gate completed. Both hosts passed 174 Rust tests with zero skips, 151 debug native cases, 89 release cases, 31 protocol tests, 33 editor tests, and the R2–R5 book lessons. See [complete evidence](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/evidence/r5-complete-2026-09-28.json) and [round report](https://github.com/jedt3d/wbasic-language/blob/main/dev-docs/rounds/R5-streams-data-libraries.md).
