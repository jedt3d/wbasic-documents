## อ่านแยกตามหนังสือ

คู่มือนี้แยกกฎของภาษาออกจากไลบรารีมาตรฐานและ API ของโมดูล ทุกหน้าอธิบาย
พฤติกรรมที่ผ่านการตรวจสอบในขอบเขต WBasic v0.3 แล้ว ส่วนข้อเสนอที่ยังไม่ได้
พัฒนาจะอยู่ในเอกสารนักพัฒนาจนกว่าจะมีหลักฐานการทำงาน

## ขอบเขตรุ่นปัจจุบัน

คู่มือรอบนี้ปรับตาม compiler/runtime **0.0.2 private experimental preview** ที่รวมใน
`main` แล้ว รวม `wb build` และ WORM SQLite ขอบเขตนี้ต่างจากแบบออกแบบภาษา draft v0.3
และสาขา editor R8B อ่าน [รุ่น compiler และเครื่องมือ]({{< relref "/implementation-status.md" >}})
ก่อนเลือกวิธีติดตั้งและตัวอย่าง

ฉบับภาษาไทยครอบคลุมตัวภาษา ไลบรารีมาตรฐาน และ API สาธารณะที่ตรวจสอบแล้วถึง
implementation ปัจจุบัน แต่ละบทมีกฎที่ชัดเจน ตัวอย่างขนาดเล็ก กรณีขอบ และ
diagnostics ที่เกี่ยวข้อง ความสามารถที่ยัง Planned หรือ Deferred จะถูกบอกตามจริง
แทนการเร่งเขียนให้ดูเหมือนพร้อม—หนังสืออ้างอิงไม่ควรแต่งนิยายแทน compiler

ภาษาไทยเป็นต้นฉบับหลัก ฉบับภาษาอังกฤษแปลจากเนื้อหาที่ผ่านการตรวจ
โดยบรรณาธิการเทคนิคแล้วตามคำสั่งของผู้ใช้ โดยรักษาขอบเขตและสถานะเดิม

## ข้อตกลงการเขียน

Keyword และชื่อ API แสดงตรงตามที่ compiler รับ โปรแกรมที่สมบูรณ์มี `Main`
หนึ่งตัว ส่วนตัวอย่างที่เป็น fragment จะระบุบริบท ชนิด ค่า และ error ใช้ชื่อ
ของ WBasic โดยตรง ไม่อาศัยความหมายจากภาษาอื่น
