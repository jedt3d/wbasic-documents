บทนี้สร้างตารางคูณขนาด 4 × 4 ด้วย `For` สองชั้น ใช้ได้ด้วยภาษาและ Core I/O โดยไม่ต้องติดตั้งไลบรารีเพิ่ม ตัวเลขเล็กช่วยให้เราตรวจด้วยตาได้ก่อนขยายงาน

## ก่อนเริ่ม

ต้องมี `wb` และ native developer toolchain ตาม Getting Started ที่ตั้งค่าแล้ว ดาวน์โหลด `main.wbas` เปิด terminal ในโฟลเดอร์ที่เก็บไฟล์ แล้วสั่ง:

```powershell
wb check main.wbas --json
wb run main.wbas
```

`check` ตรวจ source ส่วน `run` คอมไพล์ ลิงก์ และรัน การตรวจ source ผ่านอย่างเดียวจึงยังไม่พิสูจน์ว่าเครื่องพร้อมรัน native program

## ผลที่ควรได้

```text
1 2 3 4
2 4 6 8
3 6 9 12
4 8 12 16
```

ฉบับนี้พิมพ์ช่องว่างคั่นตัวเลข ไม่จัดความกว้างคอลัมน์เหมือนตารางขนาดใหญ่ จึงเป็นตารางข้อมูลที่อ่านลำดับได้ ไม่ใช่ตัวอย่างระบบจัด layout

## อ่านโค้ดทีละส่วน

{{< project-source "49-multiplication" >}}

ลูป `row` เลือกแม่คูณ ส่วนลูป `column` ไล่ตัวคูณ ภายในหนึ่งรอบของลูปนอก เราจะทำลูปในครบสี่รอบก่อนเขียนบรรทัดออกมา `For` ของ WBasic รวมค่าปลายทาง ดังนั้น `1 To 4` มีสี่ค่า

ตัวแปร `line` เริ่มว่างทุกครั้งที่ขึ้นแถวใหม่ การประกาศไว้ในลูปนอกสำคัญพอ ๆ กับสูตรคูณ หากย้ายไปก่อนลูปนอกโดยไม่ล้างค่า บรรทัดที่สองจะสะสมแถวแรกมาด้วย เครื่องไม่ได้จำเก่งผิดเวลา เราเพียงไม่ได้บอกให้เริ่มใหม่

เงื่อนไข `column > 1` เติมช่องว่างเฉพาะระหว่างค่า ทำให้ไม่มีช่องว่างหัวหรือท้ายบรรทัด เราแปลงผลคูณด้วย `.ToString()` ก่อนต่อกับ String เพราะการแปลงชนิดควรเห็นได้ชัดในโค้ด

## ตรวจความเข้าใจ

เริ่มตรวจมุมซ้ายบนเป็น 1 และมุมขวาล่างเป็น 16 แล้วตรวจแต่ละแถวเพิ่มด้วยจำนวนเท่ากับเลขแถว หากแก้ขนาดเป็น 3 ต้องเหลือสามบรรทัดและบรรทัดสุดท้ายเป็น `3 6 9` ทดสอบทั้งจำนวนแถวและค่า อย่าตรวจเพียงว่าโปรแกรมไม่ล้ม

ลองเพิ่ม procedure ที่เติมช่องว่างด้านหน้าจนข้อความยาวสามตัวก่อนต่อเข้า `line` วิธีนี้เขียนด้วย String และลูปได้ ไม่ต้องรอ API จัดรูปแบบ การใช้ความยาว String เพื่อจัดเลข ASCII ทำได้ในโจทย์นี้ แต่ไม่ควรนำไปวัดความกว้างข้อความไทยบน terminal ทั่วไป
