## เป้าหมายของโครงงาน

เพชรบนจอข้อความไม่ต้องใช้คำสั่งวาดภาพสักคำ เราต้องตอบให้ได้ว่าแต่ละแถวมีช่องว่างนำหน้ากี่ตัวและมี `*` กี่ตัว โครงงานนี้วาดเพชรทึบขนาด **3**: แถวกลางกว้างห้าดอกจัน แล้วลดลงอย่างสมมาตร ตัวอย่างใช้ขนาดเดียวที่กำหนดไว้ใน source เพื่อให้เปรียบเทียบผลลัพธ์ได้ตรงกันทุกครั้ง

## เตรียมและรัน

ดาวน์โหลด `main.wbas` แล้วเปิดเทอร์มินัลในโฟลเดอร์นั้น เครื่องพัฒนาต้องมี `wb` และชุด native SDK/runtime ที่เข้าคู่กัน:

```console
wb check main.wbas --json
wb run main.wbas
```

คำสั่งแรกตรวจ source; คำสั่งหลังคอมไพล์ ลิงก์ และรัน สำหรับผู้ที่สร้าง `wb` จากคลังผลิตภัณฑ์เอง คำสั่งสร้างชุดเครื่องมือคือ `cargo build --workspace --locked` ที่รากคลังนั้น หลักฐานตัวอย่างนี้ใช้ compiler `2614b37` ส่วนสาย R8A/R8B ที่ใหม่กว่ามี `wb build` สำหรับงานพัฒนาที่ใช้ native SDK แล้ว แต่ยังไม่ใช่การรับรองแพ็กเกจ production/no-SDK

ผลลัพธ์ด้านล่างเก็บช่องว่างหน้าดอกจันไว้ ช่องว่างเหล่านี้เป็นส่วนของรูป ไม่ใช่การจัดย่อหน้าของหนังสือ:

```text
Diamond, size 3
  *
 ***
*****
 ***
  *
```

## หาแบบแผนก่อนเขียนวงวน

ให้ `row` นับจาก 1 ถึง `size` ในครึ่งบน จำนวนช่องว่างนำหน้าคือ `size - row`; จำนวนดอกจันคือ `2 * row - 1` ดังนั้นเมื่อ `size = 3` แถวแรกมีช่องว่างสองตัวกับดอกจันหนึ่งตัว แถวสามไม่มีช่องว่างและมีดอกจันห้าตัว การคิดเป็นตารางตัวเลขก่อนเขียนโค้ดช่วยให้เห็นสูตรง่ายกว่าการเดาด้วยสายตา

`DrawRow` สร้างข้อความหนึ่งแถวจากวง `For` สองวง แล้วจึง `PrintLn` ครั้งเดียว วิธีนี้ทำให้การวาดแถวกับการเลือกว่าจะวาดแถวใดเป็นคนละหน้าที่ `Main` วาดครึ่งบนจาก 1 ถึง 3 จากนั้นครึ่งล่างเริ่มที่ `size - 1` และถอยลงถึง 1 ถ้าเริ่มครึ่งล่างที่ 3 จะได้แถวกลางซ้ำสองครั้ง; รูปจะมีเอวหนาอย่างไม่ตั้งใจ

ตัวอย่างนี้ตั้งใจวาด **เพชรทึบด้วยดอกจัน** ไม่ใช่เพชรเส้นขอบด้วยเครื่องหมายทับ ขนาดต้องเป็นจำนวนเต็มบวก ถ้าเปลี่ยน `size` เป็น 0 จะไม่เกิดแถวของรูปเลย และค่าที่ใหญ่เกินไปจะสร้างข้อความกับผลลัพธ์จำนวนมาก จึงควรเพิ่มการตรวจช่วงก่อนเปิดให้ผู้ใช้ป้อนขนาด

## ลองต่อ

1. ตั้ง `size = 1` แล้วทำนายจำนวนแถว ควรได้ดอกจันเพียงตัวเดียว
2. ตั้ง `size = 4` แล้วเขียนตาราง `(row, ช่องว่าง, ดอกจัน)` ของครึ่งบนก่อนรัน ตรวจว่ารูปสูง `2 * size - 1` แถว
3. เปลี่ยน `DrawRow` ให้วาดกรอบโดยเว้นช่องว่างด้านใน ลองคิดกรณีแถวแรกแยกต่างหาก เพราะไม่มีพื้นที่ด้านใน
