หอคอยฮานอยมีเสา A, B, C และจานขนาดต่างกัน ย้ายได้ครั้งละหนึ่งจาน โดยห้ามวางจานใหญ่บนจานเล็ก วิธีแก้สามจานมีโครงสร้างเดียวกับวิธีแก้สองจาน: ย้ายกลุ่มบนไปเสาพัก ย้ายจานใหญ่ แล้วพากลุ่มบนตามไปเสาปลายทาง บทนี้พิมพ์ลำดับการย้ายที่ถูกกฎจากสูตรเรียกซ้ำ ไม่รับการเดินจากผู้เล่น

## ลองรัน

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
disk 1: A -> C
disk 2: A -> B
disk 1: C -> B
disk 3: A -> C
disk 1: B -> A
disk 2: B -> C
disk 1: A -> C
moves 7
```

## แบ่งโจทย์ให้เล็กลง

{{< project-source "77-tower-of-hanoi-puzzle" >}}

`Move(disks, source, spare, target)` หยุดเมื่อจำนวนจานเป็นศูนย์ สำหรับจำนวนบวก มันเรียกตัวเองเพื่อย้าย `disks - 1` จานไปเสาพัก พิมพ์การย้ายจานใหญ่ที่สุดจากต้นทางสู่ปลายทาง แล้วเรียกตัวเองอีกครั้งเพื่อย้ายกองบนกลับสู่ปลายทาง ชื่อเสาทั้งสามสลับบทบาทในการเรียกแต่ละครั้ง นี่คือส่วนที่ควรไล่ด้วยดินสอสำหรับสองจานก่อนอ่านกรณีสามจาน

จำนวนการย้าย `T(n) = 2T(n-1) + 1` จึงเป็น `2^n - 1` โปรแกรมคำนวณด้วยการคูณ 2 ในลูป และตั้งขอบจาน 1–8 เพื่อให้ผลพิมพ์ไม่ยาวเกินไป ขอบนี้เป็นข้อกำหนดของตัวอย่าง ไม่ใช่ข้อจำกัดการเรียกซ้ำทั้งหมดของภาษา

## ตรวจด้วยตนเอง

ลองหนึ่งจาน ต้องพิมพ์การย้ายเดียวจาก A ไป C ลองสองจาน ควรมีสามการย้ายและไม่มีจานใหญ่บนจานเล็ก ตรวจลำดับเจ็ดบรรทัดข้างบนโดยวาดสามเสาแล้วขีดจานทุกครั้ง แบบฝึกหัดคือเขียนตัวตรวจสถานะเสาจริงเพื่อยืนยันกฎหลังแต่ละบรรทัด วิธีนั้นจะแยก *การสร้างคำตอบ* จาก *การตรวจคำตอบ* อย่างชัดเจน
