> **สถานะ: ขาด API สำหรับรูปแบบต้นทาง** ยังไม่มีไฟล์ WBasic ที่รันได้ เอกสารดาวน์โหลดเป็นแผนบท ไม่ใช่ source หรือผลทดสอบ

## โจทย์ฉบับ WBasic

แปลงข้อความที่ป้อนเป็นเสียงพูด ข้อมูลที่บทต้องเก็บคือ **ข้อความ ภาษา และสถานะเสียงพูด**

## วิธีทำที่เสนอ

ต้องเรียก TTS พร้อมจัดการภาษาไม่รองรับ

## เกณฑ์ตรวจเฉพาะบท

ข้อความว่างไม่เริ่มเสียง ข้อนี้เป็นตัวอย่าง acceptance ที่ต้องลงมือทดสอบเมื่อเขียน source ไม่ใช่ผลที่ผ่านแล้ว

## สิ่งที่ยังขาด

ขาดจริง: ไม่มี TTS/เสียงหรือ OS speech API ใน v0.3 ต้องมี speech provider ที่รับข้อความและภาษา พร้อมผลสำเร็จหรือข้อผิดพลาดที่ทดสอบได้ การพิมพ์ข้อความหรือใช้ข้อมูลกำหนดล่วงหน้าไม่ทดแทนการสร้างเสียงพูด จึงยังไม่ถือว่าทำโครงการนี้ได้ครบ
