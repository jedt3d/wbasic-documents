ภาพแบบข้อความไม่จำเป็นต้องสร้างทีละจุด เราออกแบบหน่วยเล็กหนึ่งชิ้น แล้วทำซ้ำในแนวนอนและแนวตั้ง บทนี้ใช้สองบรรทัดต่อหนึ่งแถวหกเหลี่ยม รูปร่างจงใจย่อให้เห็นหลักของการปูกระเบื้อง ไม่ใช่ภาพขนาดหรือระยะห่างเดียวกับต้นทาง

## ลองรัน

เปิดโฟลเดอร์ที่ดาวน์โหลดแล้วตรวจและรัน:

```powershell
wb check main.wbas --json
wb run main.wbas
```

## จากชิ้นส่วนสู่ภาพ

{{< project-source "35-hex-grid" >}}

`Repeat` รับข้อความหนึ่งชิ้นกับจำนวนครั้ง แล้วต่อท้าย `line` ทีละครั้ง ฟังก์ชันนี้แยก *การทำซ้ำแนวนอน* ออกจากลูปใน `Main` ซึ่งรับผิดชอบ *จำนวนแถวแนวตั้ง* จึงเปลี่ยน `width` และ `height` คนละค่าได้โดยไม่แก้รูปแบบชิ้นส่วน

เครื่องหมาย `\` ในชิ้นส่วนเป็นส่วนหนึ่งของลาย ลองดูอักขระจริงในซอร์สก่อนปรับลาย เพราะรูปที่เห็นขึ้นกับการจัดช่องว่างด้วย จำนวนบรรทัดผลลัพธ์คือ `2 * height`; การนับนี้เป็นวิธีตรวจภาพที่สะดวกกว่าใช้สายตาอย่างเดียว

## ทดลอง

ลอง `width = 1`, `height = 1` แล้วตรวจว่ามีสองบรรทัด ลองให้ `width = 0` แล้วอธิบายว่าทำไมผลเป็นบรรทัดว่าง: ลูปของ `Repeat` ไม่ทำงาน แต่ `PrintLn` ยังทำงาน หากต้องการห้ามศูนย์ ควรตรวจพารามิเตอร์ก่อนพิมพ์

แบบฝึกหัดที่ยากขึ้นคือออกแบบชิ้นส่วนสามบรรทัดและพิสูจน์ว่ารอยต่อระหว่างชิ้นไม่ขาดเมื่อทำซ้ำ หัวใจของโจทย์คือกำหนดหน้ากว้างของแต่ละชิ้นให้สัมพันธ์กัน ไม่ใช่เพิ่มจำนวนลูป
