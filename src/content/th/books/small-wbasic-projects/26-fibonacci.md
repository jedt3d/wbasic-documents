## เป้าหมายของโครงงาน

ลำดับฟีโบนักชีเริ่ม `F(0) = 0`, `F(1) = 1` และใช้ `F(n + 2) = F(n) + F(n + 1)` ต่อไปเรื่อย ๆ ในบทนี้เราพิมพ์ **สิบพจน์แรก ตั้งแต่ F(0) ถึง F(9)** โดยถือค่าก่อนหน้าสองตัวไว้ในตัวแปร ไม่ต้องเก็บทั้งลำดับลง array การระบุเลขดัชนีให้ชัดช่วยหลีกเลี่ยงความสับสนว่า “พจน์ที่หนึ่ง” หมายถึง 0 หรือ 1

## เตรียมและรัน

ดาวน์โหลด `main.wbas` แล้วเปิดเทอร์มินัลในโฟลเดอร์นั้น บนเครื่องพัฒนาที่มี `wb` พร้อม native SDK และ runtime คู่กัน:

```console
wb check main.wbas --json
wb run main.wbas
```

`check` ตรวจ source; `run` คอมไพล์ ลิงก์ และรัน ถ้าสร้าง `wb` จาก checkout ผลิตภัณฑ์ ให้รัน `cargo build --workspace --locked` ที่รากคลังนั้นก่อน หลักฐานตัวอย่างนี้ใช้ compiler `2614b37` ส่วนสาย R8A/R8B ที่ใหม่กว่ามี `wb build` สำหรับงานพัฒนาที่ใช้ native SDK แล้ว แต่ยังไม่ใช่การรับรองแพ็กเกจ production/no-SDK

ผลลัพธ์ระบุทั้งดัชนีและค่า จึงใช้ตรวจการเลื่อนค่าทีละรอบได้:

```text
First 10 Fibonacci numbers
F(0) = 0
F(1) = 1
F(2) = 1
F(3) = 2
F(4) = 3
F(5) = 5
F(6) = 8
F(7) = 13
F(8) = 21
F(9) = 34
```

## ดูการเลื่อนสถานะให้ครบสามจังหวะ

ก่อนรอบแรก `previous = 0` และ `current = 1` ซึ่งแทน `F(0)` และ `F(1)` เราพิมพ์ `previous` ก่อน แล้วคำนวณ `following = previous + current` จากนั้นเลื่อน `previous = current` และ `current = following` หลังรอบแรกจึงได้คู่ `(1, 1)` พร้อมพิมพ์ `F(1)` ในรอบถัดไป ถ้าสลับการกำหนดค่าโดยไม่เก็บ `following` ก่อน เราจะเผลอเอาค่าที่เพิ่งเปลี่ยนไปบวกอีกครั้ง ลำดับจะผิดตั้งแต่ต้น

วง `For` วิ่งจาก 0 ถึง 9 รวมสิบรอบ จำนวนบรรทัดจึงแน่นอน โปรแกรมยังคำนวณ `following` หลังพิมพ์ `F(9)` แม้จะไม่นำค่านั้นไปแสดง; ในขอบเขตเล็กนี้ไม่ก่อปัญหา แต่ถ้าขยายจำนวนพจน์ควรหลีกเลี่ยงงานเกินจำเป็นและตรวจช่วงของ `Integer` ด้วย ฟีโบนักชีโตเร็ว เมื่อบวกจนเกินค่าสูงสุดของชนิดข้อมูล โปรแกรมจะเกิดข้อผิดพลาดด้านเลขคณิต ตัวอย่างนี้ไม่ได้รับตัวเลขมหาศาลหรืออ้างว่าคำนวณลำดับได้ไม่สิ้นสุด

## ลองต่อ

1. ลดขอบบนของวง `For` เป็น 1 แล้วตรวจว่าผลมีสองพจน์ `F(0)` และ `F(1)` เท่านั้น
2. เปลี่ยนค่าเริ่มเป็น 2 และ 1 แล้วทำนายสี่พจน์แรก นี่เป็นลำดับตามกติกาเดียวกัน แต่ไม่ใช่ฟีโบนักชีมาตรฐาน
3. ปรับโปรแกรมให้พิมพ์เฉพาะพจน์ดัชนีคู่ โดยยังต้องคำนวณพจน์คี่ภายในเพื่อให้พจน์ถัดไปถูกต้อง
