**หนังสือเล่มนี้ปรับแนวคิดโครงการจาก The Big Book of Small Python Projects ของ Al Sweigart** โดยเขียนคำอธิบายและตัวอย่าง WBasic ใหม่ในสำนวนของเราเอง ขอขอบคุณผู้เขียนที่สร้างชุดโจทย์ให้ผู้อ่านได้เรียนผ่านการลงมือทำ อ่านหนังสือต้นทางได้โดยตรงที่ [Invent with Python — The Big Book of Small Python Projects](https://inventwithpython.com/bigbookpython/) และสนับสนุนผู้เขียนผ่านลิงก์บนเว็บไซต์นั้นได้

นี่เป็นหนังสือประกอบการเรียน WBasic ที่จัดทำแยกต่างหาก ไม่ใช่ฉบับแปลอย่างเป็นทางการ และไม่ได้อ้างว่าผู้เขียนต้นทางรับรอง WBasic เราใช้หมายเลขโครงการเดิมเพื่อให้ตามกลับไปศึกษาได้สะดวก แต่ลำดับเรียนไม่จำเป็นต้องเริ่มที่หมายเลข 1

## จาก Getting Started มาสู่โครงการเล็ก

เล่มนี้เป็นเล่มที่สองสำหรับอ่านต่อจาก Getting Started เมื่อรู้แล้วว่าไฟล์ source คืออะไรและใช้ `wb` อย่างไร เราจะลดขนาดโจทย์ลงให้มองเห็นการเปลี่ยน input เป็น output ได้ครบในบทเดียว โค้ดสั้นไม่ได้หมายความว่าไม่ต้องตรวจขอบเขต เพียงหมายความว่าเรามีข้ออ้างน้อยลงที่จะไม่อ่านมัน

ฉบับภาษาไทยเป็นต้นฉบับหลัก ผ่านการตรวจเนื้อหาและบรรณาธิการก่อนเริ่มฉบับอังกฤษ ผู้ใช้อนุมัติให้แปลอังกฤษในรอบถัดมา โดยรักษาโค้ดตัวอย่างและขอบเขตสถานะเดิม

## เลือกเส้นทางอ่าน

เริ่มด้วย [ตารางคูณ]({{< relref "49-multiplication.md" >}}) เพื่อฝึกลูปซ้อน ต่อด้วย [รูปเพชร]({{< relref "16-diamonds.md" >}}) เพื่อสร้างบรรทัดข้อความ จากนั้นอ่าน [ตัวประกอบ]({{< relref "24-factors.md" >}}) และ [จำนวนเฉพาะ]({{< relref "56-primes.md" >}}) เพื่อแยกกฎออกเป็น procedure

เมื่อคุ้นกับ state แล้ว ลอง [Fibonacci]({{< relref "26-fibonacci.md" >}}), [Collatz]({{< relref "12-collatz.md" >}}), [ROT13]({{< relref "61-rot13.md" >}}) และ [แกนเกม XO]({{< relref "76-tic-tac-toe.md" >}}) แต่ละบทบอกขอบเขตที่ปรับจากต้นทางไว้ ไม่เรียก replay ว่าเกมโต้ตอบ และไม่เรียกการทดลองช่วงเล็กว่าการพิสูจน์ทั่วไป

ดูโครงการทั้งหมดพร้อมสถานะและสิ่งที่ต้องเตรียมใน [แผนที่โครงการ 81 บท]({{< relref "project-roadmap.md" >}})

ฉบับนี้มีโค้ดบทเรียน 29 โครงการ และหน้าวางแผน 52 โครงการ บทที่มีโค้ดบางบทลดขอบเขตเป็นการคำนวณหนึ่งรอบหรือ replay เพื่อสอนกฎหลักก่อน ไม่ได้อ้างว่าทำงานเท่ากับโปรแกรมต้นทางทุกส่วน

กลุ่มข้อความครอบคลุมภาพจากอักขระ, Caesar, การลองกุญแจ, Leetspeak, Pig Latin, ตัวใหญ่เล็กสลับกัน และรหัสแทนที่ กลุ่มตัวเลขมีระบบฐานและตัวเลขเจ็ดขีด ส่วนกลุ่มเกมมีแกน Connect Four, Mancala, XO, Hanoi และปริศนาถังน้ำ ผู้อ่านจึงเลือกฝึกโครงสร้างข้อมูลก่อนเพิ่มการรับคำสั่งหรือหน้าจอได้

## ดาวน์โหลดและอ่านสถานะก่อนรัน

ต้นบทที่มี implementation มีลิงก์ดาวน์โหลด `main.wbas` และแสดงโค้ดจากไฟล์เดียวกัน บันทึกไฟล์ลงโฟลเดอร์ที่เขียนได้ แล้วใช้ `wb check main.wbas --json` และ `wb run main.wbas` หลังเตรียม developer toolchain ตาม Getting Started แล้ว ตัวอย่างเหล่านี้ไม่ใช่หลักฐานว่าแพ็กเกจสำหรับเครื่องที่ไม่มี SDK พร้อมแจกจ่ายแล้ว

บท placeholder แสดงสถานะก่อนเนื้อหา มีเอกสารแผนให้ดาวน์โหลดแทน source ที่ยังไม่มี ไม่ปลอมไฟล์โปรแกรมเปล่าเป็นตัวอย่างสำเร็จ และแยกเหตุผลไว้ว่าเป็นงานเขียนที่ยังรอ งานที่ต้องตรวจเพิ่ม หรือ API ที่ยังไม่มีจริง การไม่มีคำสั่งสำเร็จรูปหนึ่งคำไม่ได้แปลว่าทำโจทย์นั้นไม่ได้ หากเขียนขั้นตอนเดียวกันด้วยภาษาแกนหลักได้ เราจะบอกตามนั้น

## หลักการตรวจบทเรียน

ทุกบทที่มีโค้ดต้องมีผลคาดหวัง ขอบเขตข้อมูล และสิ่งที่ให้ลองเปลี่ยน การตรวจ source กับการรันจริงเป็นคนละขั้น เราบันทึก compiler และผลตรวจใน [บันทึกการตรวจฉบับนี้]({{< relref "verification.md" >}}) ขอบเขตแพลตฟอร์มให้ดูจากหลักฐาน ไม่อนุมานว่าโปรแกรมที่ผ่านเครื่องหนึ่งผ่านทุกเครื่อง

เลขโครงการและลิงก์ต้นทางช่วยบอกที่มาของแนวคิด ส่วนโค้ด WBasic และคำอธิบายเป็นงานเขียนใหม่ เราไม่คัดลอกข้อความ รูปภาพ หรือชุด source Python ของต้นฉบับมารวมในไฟล์ดาวน์โหลด
