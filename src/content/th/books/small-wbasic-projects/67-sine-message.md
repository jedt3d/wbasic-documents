> **สถานะ: ขาด API สำหรับรูปแบบต้นทาง** ยังไม่มีไฟล์ WBasic ที่รันได้ เอกสารดาวน์โหลดเป็นแผนบท ไม่ใช่ source หรือผลทดสอบ

## โจทย์ฉบับ WBasic

เลื่อนข้อความตามเส้นไซน์ ข้อมูลที่บทต้องเก็บคือ **ข้อความและตารางระยะเยื้อง**

## วิธีทำที่เสนอ

ใช้แพตเทิร์นคลื่นคงที่หากไม่มี Sin

## เกณฑ์ตรวจเฉพาะบท

0,1,2,1 ต้องวนกลับ 0 ข้อนี้เป็นตัวอย่าง acceptance ที่ต้องลงมือทดสอบเมื่อเขียน source ไม่ใช่ผลที่ผ่านแล้ว

## สิ่งที่ยังขาด

ขาดจริง: ไม่มี Math.Sin; ต้องเขียนตารางคลื่นคงที่หรือเพิ่ม API และพิสูจน์ TUI หากเคลื่อน ลำดับระยะเยื้องที่กำหนดเองเป็นลายคลื่นตัวอย่าง ไม่ใช่ผลของ Sin สำหรับมุมใดก็ได้ หากใช้ตารางไซน์ต้องระบุช่วงมุมและความคลาดเคลื่อน
