ROT13 เลื่อนตัวอักษรอังกฤษไปครึ่งวงของอักษร 26 ตัว เมื่อทำซ้ำจึงได้ข้อความเดิม บทนี้ใช้โจทย์นี้ฝึกการเดินผ่าน String และการเก็บอักขระที่เราไม่ได้กำหนดให้เปลี่ยนไว้ตามเดิม ไม่ใช้ซ่อนรหัสผ่านหรือข้อมูลลับ

## ทดลอง

ใช้ `wb` กับ native toolchain ตาม Getting Started จากโฟลเดอร์ดาวน์โหลด:

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
Uryyb JOnfvp! ไทย 123
Hello WBasic! ไทย 123
```

ภาษาไทย ตัวเลข ช่องว่าง และเครื่องหมายตกใจยังเหมือนเดิม บรรทัดที่สองเกิดจากแปลงผลลัพธ์บรรทัดแรกอีกครั้ง ไม่ใช่พิมพ์สำเนาตัวแปรต้นฉบับ

## กลไกของตารางจับคู่

{{< project-source "61-rot13" >}}

String `alphabet` กับ `shifted` มีความยาวเท่ากัน ตัวอักษรที่ตำแหน่งเดียวกันเป็นคู่แทนที่ เราจัดทั้งตัวใหญ่และตัวเล็กไว้ชัดเจนจึงไม่ต้องเปลี่ยน case ของข้อความก่อน

ลูป `For Each` อ่านทีละ Unicode scalar แต่ละรอบตั้ง `replacement` ให้เป็นอักขระเดิมก่อน แล้วค่อยค้นในตาราง ถ้าไม่พบก็ยังได้ค่าเดิม การตั้งค่าเริ่มต้นเช่นนี้ทำให้กรณี “นอกตัวอักษรอังกฤษ” มีพฤติกรรมชัดเจนโดยไม่ต้องเขียนรายการภาษาอื่นทั้งหมด

เมื่อพบตัวอักษรในตาราง เราใช้ index เดียวกันอ่านตารางแทนที่แล้ว `Break` ออกจากลูปค้นหา สุดท้ายต่ออักขระเข้าผลลัพธ์ ตัวอย่างนี้เลือกค้นเชิงเส้นเพื่อให้อ่านง่าย ตารางมีเพียง 52 ตัวจึงไม่มีเหตุให้เริ่มบทด้วยโครงสร้างซับซ้อน

## ทดสอบอะไรจึงพอมีความหมาย

การแปลงสองรอบกลับมาเหมือนเดิมเป็นคุณสมบัติที่ดี แต่ยังไม่พอ โปรแกรมที่ไม่แปลงอะไรเลยก็ผ่านข้อนั้น ต้องตรวจคู่ที่รู้คำตอบด้วย เช่น `A` เป็น `N`, `n` เป็น `a`, `Z` เป็น `M` และ `123` คงเดิม

ลองข้อความว่างและข้อความไทยผสม emoji โปรแกรมควรเก็บ scalar ที่นอกตารางไว้ครบ ไม่ควรเรียกความยาว String ว่าจำนวนตัวอักษรที่มองเห็น เพราะสระและวรรณยุกต์อาจใช้หลาย scalar

แบบฝึกหัด: เปลี่ยน `Main` ให้รับ `ReadLine()` แล้วใช้ `If Let` แยก EOF ออกจากบรรทัดว่าง การรับข้อความทำได้ด้วย Core I/O ที่มีอยู่ จึงเป็นงานต่อยอดของบท ไม่ใช่ข้อจำกัดไลบรารี
