> **สถานะ: ขาด API สำหรับรูปแบบต้นทาง** ยังไม่มีไฟล์ WBasic ที่รันได้ เอกสารดาวน์โหลดเป็นแผนบท ไม่ใช่ source หรือผลทดสอบ

## โจทย์ฉบับ WBasic

ฟังลำดับเสียงแล้วป้อนเลียนแบบ ข้อมูลที่บทต้องเก็บคือ **ลำดับเสียงและคำตอบผู้ฟัง**

## วิธีทำที่เสนอ

ต้องเล่นเสียงผ่าน API ที่ตรวจได้แล้วเทียบลำดับ

## เกณฑ์ตรวจเฉพาะบท

A-B-A รับ A-B-A ปฏิเสธ A-A-B ข้อนี้เป็นตัวอย่าง acceptance ที่ต้องลงมือทดสอบเมื่อเขียน source ไม่ใช่ผลที่ผ่านแล้ว

## สิ่งที่ยังขาด

ขาดจริง: ไม่มี API สร้าง/เล่นเสียง; ต้องมีเสียงและเวลารับคำตอบที่ทดสอบได้ การเทียบลำดับตัวอักษรทดสอบกติกาความจำได้ แต่ไม่ใช่เกมฟังเสียง ต้องมี audio provider และตรวจว่าเล่นแต่ละเสียงครบตามลำดับก่อนรับคำตอบ
