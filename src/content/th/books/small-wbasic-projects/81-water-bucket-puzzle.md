ถังสามใบจุ 8, 5 และ 3 ลิตร เป้าหมายคือให้ถังใบหนึ่งมีน้ำ 4 ลิตร เราทำได้เพียงเติมให้เต็ม เททิ้งทั้งหมด หรือเทจากถังหนึ่งไปอีกถังจนต้นทางว่างหรือปลายทางเต็ม ตัวอย่างเล่นตามลำดับคำสั่งที่เตรียมไว้แล้วหยุดทันทีเมื่อถึงเป้าหมาย จึงใช้ฝึกการแปลงสถานะโดยไม่มีปัญหาจากการอ่านข้อความผู้เล่น

## อ่านหนึ่งคำสั่งในฐานะการเปลี่ยนสถานะ

{{< project-source "81-water-bucket-puzzle" >}}

`capacity` ระบุความจุคงที่ ส่วน `water` เก็บปริมาณที่เปลี่ยนไป `actions` เป็น Array ของคำสั่งสามจำนวน: ชนิด, ถังต้นทาง และถังปลายทาง ชนิด 0 คือเติม ชนิด 1 คือเททิ้ง และชนิด 2 คือเทระหว่างถัง สำหรับการเท โปรแกรมคำนวณ `amount` เป็นค่าน้อยกว่าระหว่างน้ำในต้นทางกับที่ว่างของปลายทาง แล้วลบและบวกจำนวนเดียวกัน การเทจึงรักษาปริมาณน้ำรวมโดยอัตโนมัติ

ก่อนแตะ Array โปรแกรมตรวจ index ทั้งสองและห้ามเทถังลงตัวเอง หลังทุกคำสั่งมันพิมพ์สถานะก่อนตรวจเป้าหมาย การเรียงนี้ทำให้ผู้อ่านเห็นสถานะที่ชนะด้วย ตัวอย่างไปถึง 4 ลิตรในถัง 5 ลิตรหลังเทจากถัง 5 ลงถัง 3 ที่มีน้ำอยู่ 2 ลิตร จึงรับได้อีกเพียง 1 ลิตร

## ตรวจกรณีขอบ

ลองเติมถังที่เต็มอยู่แล้ว: ปริมาณต้องไม่เกินความจุ ลองเทจากถังว่าง: `amount = 0` และสถานะไม่เปลี่ยน ใส่ index 3 หรือ -1 ในคำสั่งแรกต้องรายงาน `invalid bucket` ก่อนเข้าถึง Array แบบฝึกหัดที่ลึกขึ้นคือค้นหาลำดับคำสั่งสั้นที่สุดด้วยการสำรวจสถานะที่ยังไม่เคยพบ โดยใช้คู่ปริมาณน้ำเป็นส่วนหนึ่งของสถานะ
