รหัสแทนที่แบบง่ายจับคู่อักษร A–Z กับอักษรอีกชุดที่เรียงสลับกัน อักษรเดิมทุกตัวจึงถูกแทนด้วยอักษรเดิมเสมอ โปรแกรมนี้เข้ารหัสข้อความตัวพิมพ์ใหญ่หนึ่งบรรทัดและถอดกลับ เพื่อให้เห็นว่าแผนที่เดียวกันใช้สองทิศได้เมื่อสลับตำแหน่งต้นทางกับปลายทาง

## ลองรัน

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
DTTZ QZ FGGF!
MEET AT NOON!
```

## แผนที่ต้องเป็นหนึ่งต่อหนึ่ง

{{< project-source "66-simple-substitution-cipher" >}}

`alphabet` เป็นลำดับอ้างอิง ส่วน `key` คืออักษรที่ใช้แทนตำแหน่งเดียวกัน เช่น A ตรงกับ Q และ B ตรงกับ W `Translate` เดินทีละอักขระของข้อความ ค้นตำแหน่งใน `fromAlphabet` แล้วหยิบตำแหน่งเดียวกันจาก `toAlphabet` หากไม่พบ เช่น ช่องว่างหรือ `!` ให้คงอักขระนั้นไว้ เมื่อถอดรหัส `Main` เพียงส่ง `key` เป็นต้นทาง และ `alphabet` เป็นปลายทาง

ก่อนใช้ key โปรแกรมตรวจความยาว 26 ตัว ตรวจว่าแต่ละตัวเป็น A–Z และไม่ซ้ำกัน หากมีตัวซ้ำ อักษรหลายตัวจะเข้ารหัสเป็นตัวเดียวกัน ทำให้ถอดกลับไม่แน่นอน ความถูกต้องของข้อมูลจึงเป็นส่วนหนึ่งของอัลกอริทึม ไม่ใช่แค่การป้องกันข้อความผิดพลาด

## ทดลอง

เปลี่ยน key ให้มี Q สองตัว ต้องได้ `duplicate key letter`; ใส่เลขแทนอักษรต้องได้ `key must be A-Z` ลองข้อความ `ABC XYZ` แล้วตรวจแต่ละคู่กับตำแหน่งใน key ด้วยมือ หากเพิ่มตัวพิมพ์เล็ก ให้ตัดสินใจก่อนว่าจะใช้ key อีกชุดหรือแปลง case แล้วคืนรูปแบบเดิม เพราะโปรแกรมปัจจุบันคงตัวพิมพ์เล็กไว้

รหัสนี้ใช้เรียนการจับคู่เท่านั้น รูปแบบอักษรซ้ำยังเห็นได้ใน ciphertext จึงไม่เหมาะสำหรับเก็บข้อมูลลับจริง
