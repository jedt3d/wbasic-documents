รหัสวีฌแนร์ใช้จำนวนที่เลื่อนต่างกันตามตัวอักษรของคำกุญแจ ถ้า keyword เป็น `LEMON` อักษรข้อความตัวแรกเลื่อนตาม L ตัวถัดไปตาม E แล้ววนต่อไปเรื่อย ๆ เครื่องหมายวรรคตอนถูกคงไว้และ **ไม่กินตำแหน่ง keyword** โปรแกรมเข้ารหัสข้อความคงที่แล้วถอดกลับ เพื่อให้ตรวจความสมมาตรของกฎ

## ลองรัน

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
LXFOPV EF RNHR!
ATTACK AT DAWN!
```

## ตำแหน่งในอักษรเป็นตัวเลข

{{< project-source "80-vigenere-cipher" >}}

`Position` ให้ A เป็น 0 ถึง Z เป็น 25 และให้ -1 เมื่อไม่พบ `Transform` เดินข้อความทีละอักขระ หากไม่อยู่ใน A–Z จะต่ออักขระเดิมทันที หากพบจะใช้ `used Mod keyword.Length` เลือกอักษรกุญแจ จากนั้นนำเลขของข้อความบวกเลขกุญแจและ modulo 26 เพื่อวนหลัง Z โหมดถอดใช้การลบและบวก 26 ก่อน modulo เพื่อคงผลในช่วง 0–25

`used` เพิ่มเฉพาะเมื่อแปลงอักษร ดังนั้นช่องว่างระหว่าง `ATTACK` กับ `AT` ไม่ขยับกุญแจ `Main` ตรวจ keyword ว่าไม่ว่างและมีเฉพาะ A–Z ก่อนเรียก helper; `Transform` ตั้งสมมติฐานนี้ไว้ หากนำ helper ไปใช้ที่อื่น ต้องรักษาเงื่อนไขเดียวกัน

## ทดลอง

ใช้ keyword `A` ทุกอักษรควรอยู่เดิม เพราะ A มีค่า 0 ใช้ `B` กับข้อความ `Z!` ควรได้ `A!` และถอดกลับเป็น `Z!` ลอง keyword ว่าง ต้องหยุดก่อนคำนวณ modulo ความยาวศูนย์ แบบฝึกหัดคือรองรับตัวพิมพ์เล็กโดยเก็บรูป case เดิมให้ครบ

แม้ซับซ้อนกว่าการแทนที่แบบคงที่ รหัสคลาสสิกนี้มีจุดอ่อนเมื่อใช้จริง ควรใช้เพื่อศึกษาวงรอบและสถานะของอัลกอริทึมเท่านั้น
