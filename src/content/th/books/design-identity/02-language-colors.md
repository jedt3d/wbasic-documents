WBasic ใช้สีประจำตัวเพียงห้าสี การมี palette เล็กไม่ได้ทำให้การออกแบบจนลง
ตรงกันข้าม มันบังคับให้แต่ละสีมีงานชัดเจน และทำให้หน้าใหม่ยังเป็นญาติกับหน้าเดิม
โดยไม่ต้องคัดลอก layout ทั้งหมด

## สัดส่วนที่ทำให้หน้าสงบ

หน้าโหมดสว่างใช้ Mist เป็นพื้นที่หลักประมาณ 60% ตามด้วย Charcoal 25%, Teal 10%,
Sage 3% และ Sand 2% ตัวเลขนี้เป็นภาพตั้งต้น ไม่ใช่ใบสั่งยา หน้า code-heavy ย่อมมี
Charcoal มากขึ้น ส่วนหน้าอธิบายแนวคิดอาจแทบไม่ต้องใช้ Sand

- **Teal** ใช้กับเส้นเน้น จุดรายละเอียด focus และ display text ขนาดใหญ่
- **Sage** ใช้กับแผงสนับสนุน navigation ที่เลือก และ token ใน code
- **Sand** ใช้กับ note และค่าประเภท string/number ใน code อย่างประหยัด
- **Charcoal กับ Mist** รับงานอ่านส่วนใหญ่ เพราะ contrast สำคัญกว่าความคึกคัก

Teal บน Mist มี contrast ราว 4.35:1 จึงไม่ใช้เป็นข้อความตัวเล็กทั่วไป Link ใช้
Charcoal พร้อมเส้นใต้ Teal เพื่อให้ทั้งอ่านง่ายและยังมีลายเซ็นของระบบ ส่วน
Charcoal จับคู่กับ Mist, Sage และ Sand ได้มากกว่า 7:1

## สีมีหน้าที่ แต่ไม่มีสิทธิ์พูดคนเดียว

selection ใช้ทั้งพื้น Sage น้ำหนักตัวอักษร และขอบ Teal; note มีหัวข้อเป็นคำ;
error ต้องเขียนว่าเกิดอะไรขึ้น สีอย่างเดียวไม่ควรเป็นข้อสอบตาบอดสีแบบไม่ตั้งใจ

ใน dark mode บทบาทหลักสลับเป็นพื้น Charcoal กับข้อความ Mist เส้นใต้และ focus
เปลี่ยนเป็น Sage ส่วน note ยังคง Sand กับข้อความ Charcoal ส่วน Code block จึงไม่ต้อง
แสดงละครเปลี่ยนบุคลิกเมื่อสลับธีม เพียงเพิ่มขอบ Sage ให้แยกจากพื้นรอบข้าง

Palette นี้ไม่ใช่ชุดสีสถานะที่ครบทุกกรณี หากวันหนึ่งต้องมี success, warning หรือ
critical หลายระดับ ควรออกแบบ semantic palette เพิ่มอย่างตั้งใจ ไม่จับ Teal ไปใส่
หมวกหลายใบเพียงเพราะมันยืนอยู่ใกล้มือ
