หนังสือนี้อธิบายภาษา WBasic โดยเริ่มจากโปรแกรมที่รันได้ แล้วจึงวางกฎของ
ข้อความต้นฉบับและระบบชนิด ก่อนต่อไปยังนิพจน์ การควบคุมลำดับงาน โพรซีเยอร์
ค่า โมดูล และข้อผิดพลาด

## แผนบท

| ลำดับ | บท | สถานะ |
|---:|---|---|
| 1 | โปรแกรม WBasic หนึ่งโปรแกรม | เขียนแล้ว |
| 2 | Source text, ชื่อ, literal และการจัดบรรทัด | เขียนแล้ว |
| 3 | ชนิด การประกาศ และการแปลงค่า | เขียนแล้ว |
| 4 | Expression, operator และ equality | เขียนแล้ว |
| 5 | Control flow | เขียนแล้ว |
| 6 | Procedure และ parameter | เขียนแล้ว |
| 7 | Structure และ value semantics | เขียนแล้ว |
| 8 | Null safety | เขียนแล้ว |
| 9 | Collection และข้อความ Unicode | เขียนแล้ว |
| 10 | Error และอายุของ resource | เขียนแล้ว |
| 11 | Enum และ Flags | เขียนแล้ว |
| 12 | Module, package และ visibility | เขียนแล้ว |
| 13 | Entry point, เครื่องมือ และ diagnostics | เขียนแล้ว |

คำว่า “เขียนแล้ว” หมายถึงบทอ้างอิงครอบคลุมเฉพาะพฤติกรรมที่ implementation
ปัจจุบันมีหลักฐานทดสอบผ่าน ไม่ได้หมายความว่าข้อเสนอทุกข้อใน specification draft
พร้อมใช้แล้ว ความสามารถที่ยัง Planned หรือ Deferred จะไม่ถูกยกเป็นสัญญาของภาษาในหนังสือ

สถานะหลักฐาน ณ จุดตรวจนี้คือ 71 Passed, 23 Planned และ 1 Deferred ใน behavior
catalog การทดสอบ native ครอบคลุม Windows 11 ARM64 และ macOS ARM64 ตาม environment
ที่บันทึกไว้ ส่วน Linux ARM64 และ native x86_64 ยังไม่มี acceptance matrix ครบถ้วน
การสร้างชุดแจกจ่ายบนเครื่องสะอาดที่ไม่มี SDK เป็น gate ของ R8 และยังไม่ใช่ความสามารถ
ที่หนังสือเล่มนี้รับรอง
