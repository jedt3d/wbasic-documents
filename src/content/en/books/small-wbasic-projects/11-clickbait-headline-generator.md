## WBasic project

Generate Headlines from Templates. The project needs to keep track of **three word categories and headline templates**.

## Proposed method

Choose words with a fixed seed and insert them into a template.

## Project-specific acceptance check

The same seed produces the same headline. This is an acceptance example to test when the source is written; it has not passed yet.

## Remaining gap

Verify the seeded PRNG used to select templates and words.

This project takes its starting idea from [Al Sweigart's original chapter](https://inventwithpython.com/bigbookpython/project11.html). The WBasic explanation and source will be written anew.
