## WBasic project

Navigate a Two-Dimensional Maze. The project needs to keep track of **a maze map, the player, and the exit**.

## Proposed method

Check for a wall before moving in response to a key.

## Project-specific acceptance check

A move into a wall leaves the player in place. This is an acceptance example to test when the source is written; it has not passed yet.

## Remaining gap

A fixed maze is feasible; verify TUI keys and viewport behavior.

This project takes its starting idea from [Al Sweigart's original chapter](https://inventwithpython.com/bigbookpython/project44.html). The WBasic explanation and source will be written anew.
