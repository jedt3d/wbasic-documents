## WBasic project

Count Down Bottles with Altered Letter Cases. The project needs to keep track of **the bottle-counting text and letter-case patterns**.

## Proposed method

Count down and vary letter case according to a fixed seed.

## Project-specific acceptance check

Starting at 2 counts 2, 1, 0 in order. This is an acceptance example to test when the source is written; it has not passed yet.

## Remaining gap

Specify the PRNG for case variation and verify Unicode casing.
