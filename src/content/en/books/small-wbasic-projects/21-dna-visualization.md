## WBasic project

Draw a Text-Based DNA Helix. The project needs to keep track of **the helix state and DNA base pairs**.

## Proposed method

Cycle the helix-edge pattern and insert valid A–T or C–G base pairs.

## Project-specific acceptance check

Every row contains an allowed base pair. This is an acceptance example to test when the source is written; it has not passed yet.

## Remaining gap

A static drawing is feasible; moving output requires verification of the TUI timer.

This project takes its starting idea from [Al Sweigart's original chapter](https://inventwithpython.com/bigbookpython/project21.html). The WBasic explanation and source will be written anew.
