本書では、作業時間を集計する小さなコマンドラインプログラム **Billing Time** を通して WBasic を学びます。第1～4章では、読者自身が作るプログラムを使い、ツール、プロジェクト構成、言語、コンパイラ、コマンドラインを順に確認します。第5～9章では、別途実行できる SQLite/WORM の例と検証結果を読みます。最初の4章の小さなプロジェクトとは分けて扱ってください。

現在のコマンドとマニフェストは、CLI とポータブル ZIP で対応する **コンパイラ／ランタイム 0.2.0** を使います。VS Code Extension **0.3.0** は protocol **0.1.0** を使い、このコンパイラを選びます。プロジェクトとモジュールの `toolchain` 指定は選択したコンパイラと一致させます。New Project はその版を自動で指定します。Release 0.1.0 と Extension 0.2.1/0.2.3 は過去の検証記録であり、0.2.0 のマニフェスト用ではありません。[バージョンの境界]({{< relref "/implementation-status.md" >}})も参照してください。

まず[ツールとコンパイラ]({{< relref "/books/getting-started/01-tools-and-compiler.md" >}})から始めましょう。
