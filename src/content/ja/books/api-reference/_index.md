この部は個々の API を調べるためのものです。各ページに引数の型、戻り値、エラー、対応環境の制限、検証状況を示します。対象は統合とテストを終えた API に限ります。

統合済みの R6 時点で、振る舞いの一覧は 72 合格、23 計画段階、0 保留 です。「合格」は、記録されたリビジョンで Windows 11 ARM64 と macOS ARM64 の項目別検証に合格したことを意味します。複合的な受け入れ条件すべての合格を意味するものではありません。

ウィジェットのページでは、各項目のネイティブ実例と開発段階の検証に合格した実装を説明します。振る舞いの一覧にある複合条件がすべて 合格 になったとは主張しません。API の存在と、世界中の端末での合格は別です。

OSC52 の読み取り成功例は、固定した隔離環境の Microsoft ConPTY で合格しました。古い標準ホストでの転送は確立していません。Linux ARM64、ネイティブ x86_64、SDK を入れていない新規ホスト向けの配布は受け入れ未完了です。Windows と macOS の ARM64 の結果から推測しないでください。
