**対応するバージョンを選びます。** 1〜12 章は、ローカルで検証した拡張機能 `wbasic-dev.wbasic@0.2.3` を、公開済みの実験的な非公開コンパイラ／ランタイム `0.1.0` およびプロトコルパッケージ `0.0.2` と組み合わせて使います。0.2.3 VSIX は別途入手してください。公開済み ARM64 ZIP には変更されていない 0.2.1 が同梱されています。0.2.3 の公開リリースや Marketplace 掲載はありません。[パッケージのガイド]({{< relref "/books/w-basic-extension/00-current-preview-workflow.md" >}}) から始めてください。

この開発用ガイドは **VS Code 向け WBasic 拡張機能**を、空のワークスペースから最初のプロジェクトを作り、補完と診断を使ってソースを書き、モジュールを管理し、ビルドして Test Explorer でテストする、一続きの作業で教えます。

本全体で `MyFirstWBasic` という小さなプロジェクトを使います。各章の **練習**と **確認項目**で、画像をクリックしながらコンパイラの機嫌に期待する代わりに、その手順が動いたか判断できます。

ここで扱う開発用拡張機能は `wbasic-dev.wbasic@0.2.3` です。コマンドパレットからの操作は Windows 11 ARM64 の VS Code 1.140.0 で検証しました。0.2.3 では、macOS ARM64 のエディター操作と対話型 TUI 入力は再検証していません。対応する公開済みコンパイラ、ランタイム素材、リンカーでは、ホスト SDK を使わず Run と Development Build が動きます。ソースからのビルドにはネイティブ SDK が必要です。SDK のない新規ホストでの受け入れと本番配布は未完了です。

対応するプレリリースでは [VS Code、拡張機能、コンパイラを準備する]({{< relref "/books/w-basic-extension/01-install-extension-and-compiler.md" >}}) から始めてください。
