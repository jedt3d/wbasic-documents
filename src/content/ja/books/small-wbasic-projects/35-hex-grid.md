文字の絵を1文字ずつ描く必要はありません。小さな単位を設計し、水平方向と垂直方向に繰り返します。この章では六角形の各段に2行を使います。意図して小さくした形で敷き詰めの原理を示しますが、元のプロジェクトの大きさや間隔を再現するものではありません。

## 実行してみる

ダウンロードしたファイルのフォルダーを開き、検査して実行します。

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
/ \_/ \_/ \_/ \_
\_/\_/\_/\_/
/ \_/ \_/ \_/ \_
\_/\_/\_/\_/
/ \_/ \_/ \_/ \_
\_/\_/\_/\_/
```

## 小片から絵へ

{{< project-source "35-hex-grid" >}}

`Repeat`は文字の小片と回数を受け取り、その回数だけ`line`に追加します。これにより*水平方向の反復*と`Main`ループの*垂直方向の段数*を分けられます。小片を書き直さずに`width`と`height`を独立して変えられます。

`\`文字は模様の一部です。変更前に実際のソース内の文字と空白を調べましょう。両方が位置合わせに関わります。結果は`2 * height`行です。見た目の確認に加えて行数を数えることも有効です。

## 実験

`width = 1`、`height = 1`にすると2行になります。`width = 0`の場合、空白行になる理由を説明しましょう。`Repeat`の反復はありませんが、`PrintLn`は実行されます。0を禁止するなら、印刷前に引数を検証します。

少し難しい練習として、繰り返しても端がつながる3行の小片を設計しましょう。継ぎ目をそろえるため、各小片の幅を一定にします。
