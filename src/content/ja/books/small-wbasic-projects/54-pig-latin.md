## 目的と範囲

ピッグ・ラテンは英語の簡単な言葉遊びです。母音で始まる単語には`yay`を付け、子音で始まる単語は先頭の文字を末尾へ移して`ay`を付けます。固定した文`pig apple map`には両方の例があります。この版は**英語の小文字だけを使い、単語を1つの空白で区切ります**。より広い変換器が扱う句読点、大文字、子音の連続は扱いません。

## 準備と実行

`main.wbas`をダウンロードし、そのフォルダーで端末を開きます。対応するネイティブSDKとランタイムを備えた`wb`を使ってください。

```console
wb check main.wbas --json
wb run main.wbas
```

`run`はコンパイル、リンク、実行を行います。製品ソースからWBasicをビルドする場合は、まずルートで`cargo build --workspace --locked`を実行します。記録済みの例はコンパイラ`2614b37`を使いました。統合済みのコンパイラ0.0.2には、デバッグ・リリースのプロファイルを備えた`.wproj`プロジェクト用の`wb build`がありますが、単独の`.wbas`ファイル用ではありません。実験的なパッケージにはリンク用ツールが含まれます。SDKのない新しいマシンでの受け入れ検証は未完了です。出力は次のとおりです。

```text
pig apple map
igpay appleyay apmay
```

## 単語から文に戻す

`Main`は`.Split(" ")`を呼び、各単語を`PigWord`へ渡します。この関数は`word[0]`を読む前に長さを確かめ、空の単語から守ります。先頭文字が`aeiou`に含まれれば`yay`を足し、`apple`は`appleyay`になります。それ以外では`For`ループで添字1以降の文字を集め、最初の文字と`ay`を足します。`pig`は`igpay`になります。

文を組み直すときは、`result`が空でない場合にだけ空白を足します。この例では文頭や文末に余分な空白ができません。ただし、空白が続くと`Split`が空の単語を作る可能性があり、元の空白の並びは保持できないかもしれません。一般的な文章の変換では区切りを保ち、句読点と文脈によって扱いが変わる`y`の規則を決める必要があります。
