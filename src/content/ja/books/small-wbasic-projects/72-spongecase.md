## 目的と範囲

大文字と小文字を交互にすると、Shiftキーを一定のリズムで押したように見えます。この章では`WBasic is fun!`を変換し、最初の英字を小文字、次を大文字という順にします。空白と感嘆符は順番を消費しません。規則を意図的に**決定的**にして、Booleanの状態を調べやすくし、文章の長さと変換対象の文字数が異なる理由を示します。

## 準備と実行

`main.wbas`をダウンロードし、そのフォルダーで端末を開きます。対応するネイティブSDKとランタイムを備えた`wb`を使ってください。

```console
wb check main.wbas --json
wb run main.wbas
```

`run`はコンパイル、リンク、実行を行います。製品ソースからWBasicをビルドする場合、まずルートで`cargo build --workspace --locked`を実行します。記録済みの例はコンパイラ`2614b37`を使いました。統合済みのコンパイラ0.0.2には、デバッグ・リリースのプロファイルを備えた`.wproj`プロジェクト用の`wb build`がありますが、単独の`.wbas`ファイル用ではありません。実験的なパッケージにはリンク用ツールが含まれます。SDKのない新しいマシンでの受け入れ検証は未完了です。出力は次のとおりです。

```text
WBasic is fun!
wBaSiC iS fUn!
```

## 1ビットの状態で次の文字を決める

`upperNext`は`False`から始まり、最初の英字を小文字にすることを意味します。`For Each`が文字をたどり、`letters.Contains(character)`がASCIIのa〜zとA〜Zを見分けます。一致したら`.ToUpper()`または`.ToLower()`を適用し、`Not upperNext`で状態を反転します。空白や`!`は状態を変えず、そのまま付け加えます。そのため`WBasic`の6文字の後、`is`も小文字から始まります。

代わりに`index Mod 2`を使うと空白まで数え、後のリズムが変わります。これは設計上の選択であり、すべてのスポンジケースに共通の規則ではありません。大文字・小文字を乱数で決める版もあります。この版は繰り返し可能で、A〜Zのような大小の組を持たないタイ語には交互変換を定義しません。

## 次に試すこと

1. 単語の間に`123`を挿入し、後続の英字が同じリズムを続けることを確かめます。
2. 最初の状態だけを変えて大文字から始めます。
3. 空白ごとに状態を戻し、各単語を小文字から始めて出力を比べます。
