マンカラの各プレイヤーには6つの穴と1つの貯蔵穴があります。ここではカラハの規則を使います。自分の穴1つから種をすべて取り、相手の貯蔵穴を飛ばして盤上に1つずつまきます。最後の種が自分の貯蔵穴に入ると、もう1手得られます。この章は**あらかじめ決めた4手**を再生し、状態の更新と種の総数の保存を練習します。最後まで遊ぶ完全なゲームではありません。

## 実行してみる

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
P1 pit 2 store 1
P1 pit 0 store 1
P2 pit 9 store 1
P2 pit 7 store 1
seeds 48
stores 1:1
```

## 輪になった穴を読む

{{< project-source "43-mancala" >}}

添字0～5はプレイヤー1の穴、6はその貯蔵穴、7～12はプレイヤー2の穴、13はその貯蔵穴です。手順`[2, 0, 9, 7]`には意味があります。穴2からの最後の種が貯蔵穴6に入り、P1は穴0で追加の手を得ます。その後P2は穴9を使い、同じく追加の手を得ます。

種をまくループは`position`を14を法として進め、行き先が相手の貯蔵穴でないときだけ`seeds`を減らします。最後の種が、今回落とす前は空だった自分の穴に入り（現在は1つ入っている）、向かいの穴に種があれば取り込みます。双方の種を自分の貯蔵穴へ移します。向かいの穴は`12 - position`です。

合計`seeds 48`は重要な不変条件です。種まきと取り込みは種を移動するだけで、作ったり消したりしません。合計が変わったなら更新に誤りがあります。

## 境界を確認する

最初の手を穴9に変えると`invalid pit`になります。プレイヤーを変えずに、直前に空になった穴を選ぶと`empty pit`になるはずです。相手の貯蔵穴を飛ばす手を作り、合計が48のままか確認します。完全なゲームにするなら、片方のプレイヤーの6つの穴が空になったことを検出し、残りの種をもう片方の貯蔵穴へ移して点数を比較します。
