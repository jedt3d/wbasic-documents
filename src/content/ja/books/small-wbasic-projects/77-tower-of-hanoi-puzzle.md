ハノイの塔にはA、B、Cの3本の棒と、大きさの異なる円盤があります。一度に1枚だけ動かし、小さい円盤の上に大きい円盤を置いてはいけません。3枚を解くときは2枚の場合を繰り返します。上の組を予備の棒へ移し、最大の円盤を動かしてから、上の組を目標の棒へ移します。この章は再帰で作った合法な手順を表示します。プレイヤーの手は受け付けません。

## 実行してみる

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
disk 1: A -> C
disk 2: A -> B
disk 1: C -> B
disk 3: A -> C
disk 1: B -> A
disk 2: B -> C
disk 1: A -> C
moves 7
```

## 問題を分ける

{{< project-source "77-tower-of-hanoi-puzzle" >}}

`Move(disks, source, spare, target)`は`disks`が0なら止まります。それ以外では`disks - 1`枚を予備の棒へ再帰的に移し、最大の円盤を目標へ動かす手を表示し、上の組を再び目標へ移します。呼び出しごとに棒の役割が入れ替わります。3枚の手順を読む前に、2枚の場合を紙と鉛筆でたどってください。

移動回数は`T(n) = 2T(n-1) + 1`に従い、`2^n - 1`です。プログラムはループで値を倍にして計算します。表示量を抑えるため例を1〜8枚に限ります。これはこの例の上限であり、WBasicの再帰全体の制限ではありません。

## 自分で確かめる

1枚ならAからCへ1回です。2枚なら3回で、小さい円盤の上に大きい円盤を置きません。3本の棒を描き、出力された7回の移動ごとに状態を更新してください。発展課題として独立した棒の状態検査器を書き、各手を検証します。*解の生成*と*解の検査*を分けるためです。
