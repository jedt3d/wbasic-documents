古い電卓の数字は、点灯・消灯を切り替えられる7本の短い線でできています。その状態を1つのIntegerのビットとして符号化し、複数の数字を行ごとに描きます。これで*どの線を点灯させるか*と*どう描くか*を分けられます。この例は1つのファイルであり、取り込めるモジュールではありません。

## 実行してみる

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
 _   _   _   _ 
 _| | |  _| |_ 
|_  |_| |_  |_|
```

## ビットを行に変える

{{< project-source "64-seven-segment-display-module" >}}

ビットの重みは、上が1、左上が2、右上が4、中央が8、左下が16、右下が32、下が64です。`Lit(mask, bit)`は追加のビット演算APIを使わず、整数除算と2による剰余でビットを調べます。数字8は7本すべてを点灯させるため、マスクは127です。

`DigitRow`は選んだ行に1つの数字を3文字で描きます。上の行には上の横線、中段には左上・中央・右上、下段には左下・下・右下が入ります。`Main`は4つの数字について同じ行をすべて描いてから表示します。数字を1つずつ完成させると、その数字の3行が次の数字より先に出てしまい、複数桁の表示になりません。

## 実験

`digits`を`[8]`にして7本すべてを調べます。`[1, 0]`も試してください。上の行の空白は数字の幅の一部であり、データの欠落ではありません。`masks`を添字で読む前に0〜9以外の値を退けます。発展課題として独自のマスクでマイナス記号を定義し、それが10番目の数字ではないことを明確にします。
