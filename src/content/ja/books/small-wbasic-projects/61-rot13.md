ROT13は英字を26文字のアルファベットの半周だけずらします。2回適用すると元の文章に戻ります。ここではStringを順に読み、選んだアルファベット以外の文字を保つ練習に使います。パスワードや秘密を隠すためのものではありません。

## 試してみる

『はじめに』にあるネイティブツールチェーンと`wb`を使い、ダウンロードしたファイルのフォルダーで実行します。

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
Uryyb JOnfvp! ไทย 123
Hello WBasic! ไทย 123
```

タイ語の文字、数字、空白、感嘆符は変わりません。2行目は1行目の結果を再び変換したもので、元の変数を保存して表示したものではありません。

## 対応表の働き

{{< project-source "61-rot13" >}}

`alphabet`と`shifted`は同じ長さの文字列です。同じ位置の文字が置き換えの組になります。大文字と小文字の両方を並べているので、先に文章の大小を変える必要はありません。

`For Each`はUnicodeスカラー値を1つずつ読みます。各回で`replacement`を元の文字に初期化してから表を探します。そのため、表にない文字は他の言語をすべて列挙しなくても残ります。一致したら置換表の同じ位置を使い、`Break`で検索ループを抜けます。52文字の表なら線形探索で十分分かりやすいでしょう。

## 意味のあるテスト

2回変換して元に戻る性質だけでは不十分です。何も変換しないプログラムも通ってしまいます。`A` → `N`、`n` → `a`、`Z` → `M`という既知の組と、変わらない`123`を確認してください。

空文字列と、タイ語に絵文字を混ぜた文章も試します。表の外のスカラー値はそのまま残るはずです。Stringの長さを見える文字数と同一視しないでください。タイ語の母音や声調記号は複数のスカラー値にまたがります。練習として`ReadLine()`で読み、`If Let`でEOFと空行を区別します。この拡張はCore I/Oだけでできます。
