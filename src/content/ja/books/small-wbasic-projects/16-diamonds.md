## プロジェクトの目標

文字で描くひし形には描画命令は要りません。各行の先頭の空白と`*`の個数を決めるだけです。このプロジェクトは**大きさ3の塗りつぶしたひし形**を描きます。中央の行は星印が5つで、上下の行は対称です。大きさはソース内で固定されているので、実行結果を毎回正確に比較できます。

## 準備と実行

`main.wbas`をダウンロードし、そのフォルダーで端末を開きます。開発用マシンには`wb`と対応するネイティブSDKおよびランタイムが必要です。

```console
wb check main.wbas --json
wb run main.wbas
```

最初のコマンドでソースを検査し、2番目でコンパイル、リンク、実行します。製品リポジトリから`wb`をビルドする場合は、まずルートで`cargo build --workspace --locked`を実行します。記録済みの例ではコンパイラ`2614b37`を使用しています。統合済みのコンパイラ0.0.2の`wb build`はデバッグ／リリース構成の`.wproj`プロジェクト向けであり、単独の`.wbas`ファイル向けではありません。実験用パッケージにはリンク用ツールが含まれます。SDKのない新しいマシンでの受け入れは未完了です。

以下の行頭の空白も絵の一部です。

```text
Diamond, size 3
  *
 ***
*****
 ***
  *
```

## ループを書く前に規則を見つける

上半分では`row`を1から`size`まで動かします。先頭の空白は`size - row`個、星印は`2 * row - 1`個です。`size = 3`なら、1行目は空白2つと星印1つ、3行目は空白なしで星印5つです。個数を小さな表にすると、見た目から推測するより式が分かりやすくなります。

`DrawRow`は2つの`For`ループで1行を組み立て、`PrintLn`を1回呼びます。`Main`が描く行を決めます。上半分は1から3、下半分は`size - 1`から1です。下半分を3から始めると中央の行を重複させます。これは意図して作る**塗りつぶした星印のひし形**で、斜線だけの輪郭ではありません。大きさは正でなければなりません。0なら形は出ず、非常に大きな値を入力から受け入れる際には範囲の確認が必要です。

## 次に試すこと

1. `size = 1`にしましょう。1行に星印が1つ表示されるはずです。
2. `size = 4`にし、上半分について`(row, spaces, stars)`を表にしましょう。形全体が`2 * size - 1`行になることを確かめます。
3. `DrawRow`を変え、内部に空白のある輪郭を描きましょう。最初の行には内部がないので別に扱います。
