ヴィジュネル暗号はキーワードに従って文字のずらし幅を変えます。`LEMON`なら文章の最初の文字にはL、次にはEという順で使い、最後まで行くとキーワードを繰り返します。句読点は変えず、**キーワードの位置も進めません**。このプログラムは固定した文章を暗号化して再び復号し、規則が逆向きにも働くことを確かめます。

## 実行してみる

```powershell
wb check main.wbas --json
wb run main.wbas
```

```text
LXFOPV EF RNHR!
ATTACK AT DAWN!
```

## アルファベットの位置を数にする

{{< project-source "80-vigenere-cipher" >}}

`Position`はAを0、Zを25とし、それ以外には-1を返します。`Transform`は文章を順に読みます。A〜Z以外なら元の文字をそのまま足します。英字なら`used Mod keyword.Length`でキーワードの文字を選びます。暗号化ではその位置を文章の文字の位置に足し、26の剰余でZの先へ回り込みます。復号では引き算をし、剰余の前に26を足して結果を0〜25に収めます。

`used`は英字を変換した後だけ増えるため、`ATTACK`と`AT`の間の空白ではキーワードは進みません。`Main`は補助関数を呼ぶ前に、キーワードが空でなく、A〜Zだけを含むことを確かめます。別の呼び出し元が`Transform`を使う場合も、この前提を守る必要があります。

## 実験

キーワード`A`では位置が0なので文字は変わりません。`B`では`Z!`が`A!`になり、復号すると戻るはずです。空のキーワードは、長さ0で剰余を取る前に退けます。発展課題として、大文字・小文字を保ったまま小文字にも対応します。

この古典暗号には実用上の弱点があります。ここでは現代的なデータ保護ではなく、周期とアルゴリズムの状態を学ぶために使います。
