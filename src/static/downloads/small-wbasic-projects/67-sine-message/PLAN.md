# แผนโครงการ 67: เลื่อนข้อความตามเส้นไซน์

สถานะ: ขาด API สำหรับรูปแบบต้นทาง; ยังไม่มี main.wbas

แนวคิด: เลื่อนข้อความตามเส้นไซน์
ข้อมูล: ข้อความและตารางระยะเยื้อง
ขั้นตอน: ใช้แพตเทิร์นคลื่นคงที่หากไม่มี Sin
เกณฑ์ตรวจ: 0,1,2,1 ต้องวนกลับ 0
ข้อจำกัด: ขาดจริง: ไม่มี Math.Sin; ต้องเขียนตารางคลื่นคงที่หรือเพิ่ม API และพิสูจน์ TUI หากเคลื่อน ลำดับระยะเยื้องที่กำหนดเองเป็นลายคลื่นตัวอย่าง ไม่ใช่ผลของ Sin สำหรับมุมใดก็ได้ หากใช้ตารางไซน์ต้องระบุช่วงมุมและความคลาดเคลื่อน
