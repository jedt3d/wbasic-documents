# 課題67の計画：文字列を正弦波に沿って動かす

状態：元の形式に必要なAPIが不足。まだmain.wbasはありません。

目的：文字列を正弦波に沿って動かす。
データ：文字列と、横方向のずれを記した表。
方法：Sinが使えない間は、固定された波形パターンを使う。
受け入れ条件：ずれが0、1、2、1と進んだ後、0に戻る。
残る課題：元の形に必要なMath.Sin APIがない。選んだずれの列は波形の例であり、任意の角度に対する正弦の値ではない。正弦の参照表を使うなら角度の範囲と誤差を示す。出力を動かすにはTUIの検証も必要。

出典：『The Big Book of Small Python Projects』の著者Al Sweigart。このWBasic向け計画は、原案を基に新しい言葉で書きました。
