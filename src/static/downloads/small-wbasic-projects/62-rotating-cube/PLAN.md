# แผนโครงการ 62: วาดลูกบาศก์หมุนในภาพตัวอักษร

สถานะ: ขาด API สำหรับรูปแบบต้นทาง; ยังไม่มี main.wbas

แนวคิด: วาดลูกบาศก์หมุนในภาพตัวอักษร
ข้อมูล: จุดยอด มุมหมุน และฉายลงจอ
ขั้นตอน: ใช้ sin/cos หรือตารางค่ามุมจำกัด แล้วฉายจุดและวาด
เกณฑ์ตรวจ: หมุนครบวงกลับพิกัดเดิมใน tolerance
ข้อจำกัด: ขาดจริง: ต้องมี sin/cos หรือเขียนตารางค่ามุมพร้อมพิสูจน์เลข Float และ TUI frame ตารางค่ามุมที่คำนวณไว้ใช้สอนการฉายภาพได้ แต่ต้องบอกความละเอียดของมุมและตรวจค่าคลาดเคลื่อน ส่วน animation ยังต้องผ่าน event/frame ของ TUI
