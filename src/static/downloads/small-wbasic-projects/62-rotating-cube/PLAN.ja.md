# 課題62の計画：文字で回転する立方体を描く

状態：元の形式に必要なAPIが不足。まだmain.wbasはありません。

目的：文字で回転する立方体を描く。
データ：頂点、回転角、画面への投影。
方法：正弦・余弦または範囲を限った角度表を使い、頂点を投影して描く。
受け入れ条件：一回転後、投影座標が明示した許容誤差の範囲で開始値に戻る。
残る課題：元の形に必要な三角関数APIがない。事前計算した角度表なら投影を学べるが、角度の刻み幅と数値誤差を明示して検証する必要がある。Float計算とTUIフレームも検証する。アニメーションにはTUIイベントとフレーム描画が必要。

出典：『The Big Book of Small Python Projects』の著者Al Sweigart。このWBasic向け計画は、原案を基に新しい言葉で書きました。

原案：https://inventwithpython.com/bigbookpython/project62.html
