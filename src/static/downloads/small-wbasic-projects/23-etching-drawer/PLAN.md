# แผนโครงการ 23: ใช้ปุ่มทิศทางวาดเส้นในตาราง

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: ใช้ปุ่มทิศทางวาดเส้นในตาราง
ข้อมูล: ตารางรอยวาดและตำแหน่งปากกา
ขั้นตอน: รับคีย์ทิศ ย้ายในขอบ แล้วทำเครื่องหมาย
เกณฑ์ตรวจ: ตาราง 3×3 กดขวา/ลงเกิดรอยสามช่อง
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์เหตุการณ์คีย์ TUI และการเก็บตารางระหว่าง resize
