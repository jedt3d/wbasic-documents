# Project 22 Plan: Move Ducklings Across the Screen

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Move Ducklings Across the Screen.
Data: each duckling's position and multirow drawing.
Method: Move ducklings on each tick and remove any that have left the screen.
Acceptance check: A duckling beyond the edge no longer remains in state.
Remaining gap: Verify the TUI timer, viewport, and seeded PRNG controlling spacing.
