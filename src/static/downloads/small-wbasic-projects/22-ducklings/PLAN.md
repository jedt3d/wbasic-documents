# แผนโครงการ 22: แสดงลูกเป็ดหลายตัวเคลื่อนผ่านจอ

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แสดงลูกเป็ดหลายตัวเคลื่อนผ่านจอ
ข้อมูล: ตำแหน่งลูกเป็ดและรูปหลายแถว
ขั้นตอน: เลื่อนทุก tick แล้วลบตัวที่พ้นจอ
เกณฑ์ตรวจ: ตัวพ้นขอบไม่ค้างใน state
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ TUI timer, viewport และ PRNG ระยะห่าง
