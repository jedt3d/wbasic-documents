# プロジェクト22の計画：アヒルの子を画面上で動かす

状態：実装・検証待ち。main.wbasはまだありません。

目標：アヒルの子を画面上で動かす。
データ：各アヒルの子の位置と複数行の絵。
方法：刻みごとにアヒルの子を動かし、画面外に出たものを取り除く。
受け入れ確認：端を越えたアヒルの子は状態に残らない。
残る課題：TUIタイマー、表示領域、間隔を制御するシード付き疑似乱数生成器を検証する。
