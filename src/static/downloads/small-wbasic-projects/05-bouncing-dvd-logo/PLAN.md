# แผนโครงการ 05: ขยับโลโก้ชนขอบจอและนับการชนมุม

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: ขยับโลโก้ชนขอบจอและนับการชนมุม
ข้อมูล: พิกัด ทิศ และขนาดจอ
ขั้นตอน: ขยับทุก tick แล้วสะท้อนเมื่อชนขอบ
