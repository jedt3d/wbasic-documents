# แผนโครงการ 42: ตอบคำถามด้วยชุดคำทำนาย

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: ตอบคำถามด้วยชุดคำทำนาย
ข้อมูล: ชุดคำทำนายและคำถาม
ขั้นตอน: อ่านคำถาม เลือกคำตอบจาก seed จน EOF
เกณฑ์ตรวจ: seed เดิมให้ลำดับคำตอบเดิม
ข้อจำกัด: ต้องตรวจ: ต้องเลือกคำตอบด้วย PRNG หรือให้ seed เพื่อทำซ้ำ
