# Project 42 Plan: Answer Questions with Fortune Responses

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Answer Questions with Fortune Responses.
Data: a collection of fortunes and the user's questions.
Method: Read each question, choose a response from a fixed seed, and continue until EOF.
Acceptance check: The same seed yields the same sequence of responses.
Remaining gap: Use a PRNG or supplied seed to make response selection repeatable.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.

Original idea: https://inventwithpython.com/bigbookpython/project42.html
