# Project 31 Plan: Guess a Number with Higher-or-Lower Clues

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Guess a Number with Higher-or-Lower Clues.
Data: the secret-number bounds and guess count.
Method: Choose the secret number from a fixed seed and respond whether a guess is too high or too low.
Acceptance check: With secret number 7, guessing 5 gets a higher clue.
Remaining gap: Verify the PRNG used to select the secret number. A mode with a predetermined number is feasible.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
