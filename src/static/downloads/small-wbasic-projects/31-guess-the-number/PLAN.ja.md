# プロジェクト31の計画：高い・低いの手がかりで数字を当てる

状態：実装・検証待ち。main.wbasはまだありません。

目標：高い・低いの手がかりで数字を当てる。
データ：秘密の数字の範囲と推測回数。
方法：固定シードから秘密の数字を選び、推測が高すぎるか低すぎるかを答える。
受け入れ確認：秘密の数字が7なら、5という推測には「もっと高い」と伝える。
残る課題：秘密の数字を選ぶ疑似乱数生成器を検証する。あらかじめ決めた数字を使う方式なら実現可能である。
