# แผนโครงการ 34: ทายตัวอักษรจำกัดครั้งพร้อมภาพความผิดพลาด

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: ทายตัวอักษรจำกัดครั้งพร้อมภาพความผิดพลาด
ข้อมูล: คำเป้าหมาย ตัวที่เดา และโทษ
ขั้นตอน: เปิดทุกตำแหน่งตัวที่ถูกและไม่นับเดาซ้ำ
เกณฑ์ตรวจ: BANANA เดา A เปิดสามช่อง
ข้อจำกัด: ต้องตรวจ: ต้องสุ่มคำจากคลังคำ; ตรวจ Unicode scalar กับภาพหลายบรรทัด
