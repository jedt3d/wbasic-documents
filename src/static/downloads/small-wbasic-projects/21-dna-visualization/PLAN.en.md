# Project 21 Plan: Draw a Text-Based DNA Helix

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Draw a Text-Based DNA Helix.
Data: the helix state and DNA base pairs.
Method: Cycle the helix-edge pattern and insert valid A–T or C–G base pairs.
Acceptance check: Every row contains an allowed base pair.
Remaining gap: A static drawing is feasible; moving output requires verification of the TUI timer.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
