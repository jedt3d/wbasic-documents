# แผนโครงการ 47: สร้างภาพสี่เหลี่ยมสีแบบมอนเดรียน

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: สร้างภาพสี่เหลี่ยมสีแบบมอนเดรียน
ข้อมูล: พื้นที่ สี่เหลี่ยมย่อย และสี
