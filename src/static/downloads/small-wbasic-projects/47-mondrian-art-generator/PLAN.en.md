# Project 47 Plan: Generate Mondrian-Style Rectangles

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Generate Mondrian-Style Rectangles.
Data: the canvas, subdivided rectangles, and colors.
Method: Split the canvas using seeded choices, then draw lines and colors within the viewport.
Acceptance check: No subdivided rectangle exceeds the screen bounds.
Remaining gap: Verify TUI color, viewport dimensions, and the PRNG used for positions.
