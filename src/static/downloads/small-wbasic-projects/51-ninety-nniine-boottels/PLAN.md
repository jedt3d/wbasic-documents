# แผนโครงการ 51: แปลงบทนับขวดให้ตัวพิมพ์สลับและเพี้ยน

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แปลงบทนับขวดให้ตัวพิมพ์สลับและเพี้ยน
ข้อมูล: ข้อความนับขวดและรูปแบบตัวพิมพ์
ขั้นตอน: นับถอยหลังแล้วสลับ case จาก seed
เกณฑ์ตรวจ: เริ่ม 2 ต้องนับ 2,1,0 ตามลำดับ
ข้อจำกัด: ต้องตรวจ: ต้องกำหนด PRNG การสลับรูปแบบ และตรวจ Unicode casing
