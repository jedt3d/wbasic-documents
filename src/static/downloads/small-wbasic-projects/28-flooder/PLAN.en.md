# Project 28 Plan: Recolor a Connected Grid Region

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Recolor a Connected Grid Region.
Data: a color grid, starting cell, and replacement color.
Method: Find all old-color cells connected in four directions and replace them as one region.
Acceptance check: A connected group of three A cells changes all three cells.
Remaining gap: The flood-fill algorithm is feasible; verify TUI key input and color rendering.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
