# แผนโครงการ 28: เปลี่ยนสีช่องติดกันจนตารางเป็นสีเดียว

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: เปลี่ยนสีช่องติดกันจนตารางเป็นสีเดียว
ข้อมูล: ตารางสี จุดเริ่ม และสีใหม่
ขั้นตอน: ค้นสีเดิมที่ติดกันสี่ทิศแล้วแทนพร้อมกัน
เกณฑ์ตรวจ: กลุ่ม A สามช่องติดกันเปลี่ยนครบสามช่อง
ข้อจำกัด: ต้องตรวจ: อัลกอริทึม flood fill ทำได้; ต้องพิสูจน์การรับคีย์และสี TUI
