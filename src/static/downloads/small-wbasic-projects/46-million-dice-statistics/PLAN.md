# แผนโครงการ 46: นับความถี่ผลทอยจำนวนมาก

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: นับความถี่ผลทอยจำนวนมาก
ข้อมูล: ความถี่ผลรวม 2–12
ขั้นตอน: ทอยสองลูกจาก seed ล้านรอบแล้วนับ bucket
เกณฑ์ตรวจ: ผลรวมทุก bucket เท่าหนึ่งล้าน
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ PRNG, ช่วง Integer และเวลารันหนึ่งล้านรอบ
