# แผนโครงการ 48: จำลองการเลือกประตูและสลับเพื่อเทียบโอกาส

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: จำลองการเลือกประตูและสลับเพื่อเทียบโอกาส
ข้อมูล: ประตูสามบาน รางวัล และการเปิด
ขั้นตอน: เปิดประตูแพ้ที่ไม่ใช่ตัวเลือก ก่อนเทียบ stay/switch
เกณฑ์ตรวจ: รางวัล 1 เลือก 2 ต้องเปิด 3 แล้วสลับชนะ
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ PRNG และกติกาพิธีกรที่เปิดประตูแพ้
