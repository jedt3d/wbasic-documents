# แผนโครงการ 55: เปรียบเทียบสลากกับเลขที่ออกรางวัลหลายครั้ง

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: เปรียบเทียบสลากกับเลขที่ออกรางวัลหลายครั้ง
ข้อมูล: สลาก เลขออก และรอบจำลอง
ขั้นตอน: สร้างเลขไม่ซ้ำจาก seed แล้วนับผลตรง
เกณฑ์ตรวจ: แต่ละสลากไม่มีเลขซ้ำ
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ PRNG, เลขไม่ซ้ำและข้อจำกัดจำลองจำนวนมาก
