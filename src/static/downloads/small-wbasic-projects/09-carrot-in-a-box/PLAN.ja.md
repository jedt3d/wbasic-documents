# プロジェクト09の計画：箱の中のニンジンで遊ぶ

状態：実装・検証待ち。main.wbasはまだありません。

目標：箱の中のニンジンで遊ぶ。
データ：2つの箱、ニンジンの位置、各プレイヤーの答え。
方法：固定シードでニンジンを入れる箱を選び、回答者が箱を選ぶまで中身を隠す。
受け入れ確認：公開前、回答者には箱は見えるがニンジンは見えない。
残る課題：検証済みのシード付き疑似乱数生成器で箱を選び、コンソールでの表示が回答者に情報を実際に隠せるか試す。
