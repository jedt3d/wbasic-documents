# แผนโครงการ 09: เกมสองคนเลือกกล่องจากคำบอกและการหลอกล่อ

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: เกมสองคนเลือกกล่องจากคำบอกและการหลอกล่อ
ข้อมูล: กล่องสองใบ ตำแหน่งแครอต และคำตอบ
ขั้นตอน: เลือกตำแหน่งจาก seed; ซ่อนจากผู้ทายจนเลือกแล้ว
เกณฑ์ตรวจ: ผู้ทายเห็นกล่องแต่ไม่เห็นแครอตก่อนเฉลย
ข้อจำกัด: ต้องตรวจ: ต้องกำหนดการเลือกกล่องด้วย PRNG; การซ่อนข้อมูลผู้เล่นบนคอนโซลต้องทดสอบ UX
