# Project 33 Plan: Find a Password from Positional Matches

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Find a Password from Positional Matches.
Data: a list of equal-length words and the answer.
Method: Choose the answer with a fixed seed and count matching positions in each guess.
Acceptance check: Comparing CAT with CAR gives two positional matches.
Remaining gap: The comparison rule is feasible; selecting the answer randomly needs a verified PRNG.

Credit: Al Sweigart, author of The Big Book of Small Python Projects. This WBasic chapter plan reworks the idea in new words.
