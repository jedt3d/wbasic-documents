# Project 70 Plan: Display and Adjust a Japanese Abacus

Status: Awaiting implementation and verification; no main.wbas exists yet.

Goal: Display and Adjust a Japanese Abacus.
Data: upper and lower beads in each place.
Method: Move the selected bead and calculate the value from beads touching the beam.
Acceptance check: One upper bead and two lower beads represent 7.
Remaining gap: A static image is feasible; key control and state changes need TUI verification.
