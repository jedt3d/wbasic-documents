# 課題69の計画：ゆっくり進むカタツムリを競走させる

状態：実装と検証待ち。まだmain.wbasはありません。

目的：ゆっくり進むカタツムリを競走させる。
データ：各カタツムリ、その位置、ゴール。
方法：タイマーの各回で、固定シードから各カタツムリの進む量を選ぶ。
受け入れ条件：どのカタツムリもゴールを越えない。
残る課題：進む速さを選ぶ疑似乱数生成器、TUIタイマー、複数マスにまたがる描画を検証する。
