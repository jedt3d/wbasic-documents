# แผนโครงการ 69: แข่งหอยทากที่ค่อย ๆ เคลื่อน

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แข่งหอยทากที่ค่อย ๆ เคลื่อน
ข้อมูล: หอยทาก ตำแหน่ง และเส้นชัย
ขั้นตอน: เลือกความคืบหน้าจาก seed ต่อ tick
