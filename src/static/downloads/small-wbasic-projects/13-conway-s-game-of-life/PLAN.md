# แผนโครงการ 13: คำนวณชีวิตบนตารางรุ่นต่อรุ่น

สถานะ: `draft.wbas.txt` ผ่าน `wb check --json` ด้วย compiler ที่ตรึงไว้โดยไม่มี diagnostic; ยังไม่ผ่านการรัน native/เกณฑ์รับงาน และยังไม่มี `main.wbas`

เป้าหมาย: คำนวณหนึ่งรุ่นจากตาราง Boolean 5×5 แล้วพิมพ์รุ่นก่อน/หลัง ไม่ทำหน้าจอสด
ข้อมูล: Array ซ้อนกัน; True=มีชีวิต; ขอบนอกตารางตาย ไม่วนทะลุ
วิธี: นับเพื่อนบ้านแปดทิศจากตารางเดิมเสมอ; รุ่นใหม่มีชีวิตเมื่อเพื่อนบ้าน=3 หรือเซลล์เดิมมีชีวิตและเพื่อนบ้าน=2; สร้าง Array ใหม่ก่อนแทนค่ารุ่น
รอยเดินมือ: เส้นแนวนอน (2,1),(2,2),(2,3) ทำให้ (1,2),(2,2),(3,2) มีชีวิตในรุ่นถัดไป
เกณฑ์ที่ต้องตรวจ: Given เส้นแนวนอน Then เส้นแนวตั้ง; Given ตารางตาย Then ยังตาย; Given บล็อก 2×2 Then คงเดิม; Given มุมเดี่ยว Then ตาย
ขอบเขต/งานค้าง: ต้องรัน native หนึ่งและหลายรุ่น, ตรวจตารางผิดรูปและขอบ การเล่นสดต้องออกแบบ event loop/terminal กับ TUI/Jobs ที่มีอยู่และทดสอบจริง ไม่ใช่คำขอ API ใหม่
แบบฝึกหัด: คำนวณรุ่น 2 ด้วยมือและแยกการพิมพ์จากการคำนวณ

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
