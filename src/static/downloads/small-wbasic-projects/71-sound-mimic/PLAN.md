# แผนโครงการ 71: ฟังลำดับเสียงแล้วป้อนเลียนแบบ

สถานะ: ขาด API สำหรับรูปแบบต้นทาง; ยังไม่มี main.wbas

แนวคิด: ฟังลำดับเสียงแล้วป้อนเลียนแบบ
ข้อมูล: ลำดับเสียงและคำตอบผู้ฟัง
ขั้นตอน: ต้องเล่นเสียงผ่าน API ที่ตรวจได้แล้วเทียบลำดับ
เกณฑ์ตรวจ: A-B-A รับ A-B-A ปฏิเสธ A-A-B
ข้อจำกัด: ขาดจริง: ไม่มี API สร้าง/เล่นเสียง; ต้องมีเสียงและเวลารับคำตอบที่ทดสอบได้ การเทียบลำดับตัวอักษรทดสอบกติกาความจำได้ แต่ไม่ใช่เกมฟังเสียง ต้องมี audio provider และตรวจว่าเล่นแต่ละเสียงครบตามลำดับก่อนรับคำตอบ
