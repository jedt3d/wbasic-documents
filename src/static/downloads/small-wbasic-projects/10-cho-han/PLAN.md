# แผนโครงการ 10: พนันผลคี่หรือคู่จากลูกเต๋าสองลูก

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: พนันผลคี่หรือคู่จากลูกเต๋าสองลูก
ข้อมูล: ลูกเต๋าสองลูกและคำทายคี่คู่
ขั้นตอน: สร้างแต้ม 1–6 แล้วเทียบผลรวม
เกณฑ์ตรวจ: 2+5 เป็นคี่
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์ PRNG ลูกเต๋าที่กำหนด seed ได้; ไม่มี public API สำหรับการสุ่ม

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
