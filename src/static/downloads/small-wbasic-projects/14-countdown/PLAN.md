# แผนโครงการ 14: แสดงตัวเลขลดลงตามเวลา

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แสดงตัวเลขลดลงตามเวลา
ข้อมูล: เลขเริ่มนับและ tick
ขั้นตอน: ลดหนึ่งต่อ TimerEvent ใน TUI แล้วหยุดศูนย์
เกณฑ์ตรวจ: เริ่ม 3 แสดง 3,2,1,0 ไม่มีค่าติดลบ
ข้อจำกัด: ต้องตรวจ: ใช้ TUI timer ภายใน session ได้ โดยทดสอบการเริ่ม หยุด และคืนโหมด terminal การนับช่วงเวลาไม่จำเป็นต้องอ่าน wall clock การป้อน tick จำลองช่วยทดสอบกฎนับถอยหลัง แต่ยังต้องรัน timer และการแสดงผลจริงก่อนเรียกว่านาฬิกานับถอยหลังที่ผ่านการตรวจ

ขอขอบคุณ Al Sweigart ผู้เขียน The Big Book of Small Python Projects; แผนบท WBasic นี้เขียนใหม่จากแนวคิดต้นทาง
