# แผนโครงการ 19: แสดงเวลาปัจจุบันแบบนาฬิกาดิจิทัล

สถานะ: ขาด API สำหรับรูปแบบต้นทาง; ยังไม่มี main.wbas

แนวคิด: แสดงเวลาปัจจุบันแบบนาฬิกาดิจิทัล
ข้อมูล: ชั่วโมง นาที วินาที และสัญญาณวาด
ขั้นตอน: อ่าน wall clock เมื่อมี API; timer แค่สั่งวาดใหม่
เกณฑ์ตรวจ: เวลา 09:05:07 ต้องแสดงตรง ไม่เดาจาก tick
ข้อจำกัด: ขาดจริง: ไม่มี wall clock/DateTime API; TUI timer อย่างเดียวบอกเวลา ณ ปัจจุบันไม่ได้ การส่งเวลา 09:05:07 ที่กำหนดไว้ให้ renderer เป็นเพียงการทดสอบรูปแบบตัวเลข ยังไม่ใช่นาฬิกาที่อ่านเวลาปัจจุบันได้
