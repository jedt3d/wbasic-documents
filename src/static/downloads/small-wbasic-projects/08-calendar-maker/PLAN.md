# แผนโครงการ 08: พิมพ์ปฏิทินรายเดือนจากปีและเดือน

สถานะ: `draft.wbas.txt` ผ่าน `wb check --json` ด้วย compiler ที่ตรึงไว้โดยไม่มี diagnostic; ยังไม่ผ่านการรัน native/เกณฑ์รับงาน และยังไม่มี `main.wbas`

เป้าหมาย: พิมพ์เดือนหนึ่งจากปี 1–9999 เดือน 1–12 ที่ระบุใน Main ไม่อ่านนาฬิกาเครื่อง
ข้อมูล: ปี เดือน วันแรกของเดือนในคอลัมน์จันทร์=0 ถึงอาทิตย์=6; ใช้ Gregorian แบบย้อนหลัง
วิธี: leap year หาร 400 ลงตัว หรือหาร 4 ลงตัวแต่ไม่หาร 100; วันก่อน 1 มกราคมปี y = (y−1)×365 + (y−1) Div 4 − (y−1) Div 100 + (y−1) Div 400; บวกวันเดือนก่อนหน้าแล้ว Mod 7 เติมช่องว่างสามตัวก่อนวันแรก พิมพ์วันช่องละสามตัว
รอยเดินมือ: 2000-02 มีวันก่อนเดือน 730150, Mod 7 = 1 จึงเริ่มอังคาร และมี 29 วัน
เกณฑ์ที่ต้องตรวจ: Given 2000-02 Then วันแรกอังคารและมี 29; Given 1900-02 Then มี 28; Given 2024-09 Then วันแรกอาทิตย์; Given เดือน/ปีนอกช่วง Then แจ้งข้อผิดพลาด
ขอบเขต/งานค้าง: ต้องรัน native, ตรวจปีขอบ 1/9999, parse ข้อมูลผู้ใช้แยก EOF/ผิดรูป การขอเดือนปัจจุบันจากนาฬิกาเครื่องคือคำขอไลบรารี SWP-FR-02; ไม่สมมติ DateTime/Calendar
แบบฝึกหัด: แยกการคำนวณจากการจัดหน้าก่อนเพิ่ม input แบบ ReadLine และ Integer.Parse
