# แผนโครงการ 74: แปลงข้อความที่ป้อนเป็นเสียงพูด

สถานะ: ขาด API สำหรับรูปแบบต้นทาง; ยังไม่มี main.wbas

แนวคิด: แปลงข้อความที่ป้อนเป็นเสียงพูด
ข้อมูล: ข้อความ ภาษา และสถานะเสียงพูด
ขั้นตอน: ต้องเรียก TTS พร้อมจัดการภาษาไม่รองรับ
เกณฑ์ตรวจ: ข้อความว่างไม่เริ่มเสียง
ข้อจำกัด: ขาดจริง: ไม่มี TTS/เสียงหรือ OS speech API ใน v0.3 ต้องมี speech provider ที่รับข้อความและภาษา พร้อมผลสำเร็จหรือข้อผิดพลาดที่ทดสอบได้ การพิมพ์ข้อความหรือใช้ข้อมูลกำหนดล่วงหน้าไม่ทดแทนการสร้างเสียงพูด จึงยังไม่ถือว่าทำโครงการนี้ได้ครบ
