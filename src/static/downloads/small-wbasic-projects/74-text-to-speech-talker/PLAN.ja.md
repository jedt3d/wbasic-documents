# 課題74の計画：入力された文章を声に出して読む

状態：元の形式に必要なAPIが不足。まだmain.wbasはありません。

目的：入力された文章を声に出して読む。
データ：文章、言語、読み上げ状態。
方法：音声合成の提供元を呼び出し、未対応の言語を処理する。
受け入れ条件：空の文章では読み上げを開始しない。
残る課題：元の形に必要なTTS、音声、OSの読み上げAPIがv0.3にはない。提供元は文章と言語を受け取り、検証可能な成功またはエラーを返す必要がある。文章の表示や事前データの利用では音声が生成されないため、この課題は完成しない。

出典：『The Big Book of Small Python Projects』の著者Al Sweigart。このWBasic向け計画は、原案を基に新しい言葉で書きました。
