# แผนโครงการ 45: แสดงมุมมองทางเดินเขาวงกตแบบสามมิติอักษร

สถานะ: รอการพิสูจน์และการเขียน source; ยังไม่มี main.wbas

แนวคิด: แสดงมุมมองทางเดินเขาวงกตแบบสามมิติอักษร
ข้อมูล: ผังเขาวงกต ทิศ และมุมมอง
ขั้นตอน: แปลงผนังหน้า/ข้างเป็นภาพแล้วรับหมุน/เดิน
เกณฑ์ตรวจ: หมุนขวาสี่ครั้งกลับทิศเดิม
ข้อจำกัด: ต้องตรวจ: ต้องพิสูจน์การเรนเดอร์มุมมองและคีย์ TUI บนเครื่องจริง
