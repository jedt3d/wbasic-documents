# Billing Time command-line starter

This is the runnable project used by the **Getting Started** ebook. From the
WBasic compiler checkout, check and run it with:

```text
wb check path/to/BillingTime.wproj --json
wb run path/to/BillingTime.wproj -- "Website refresh"
```

The current developer CLI compiles, links, and runs through `wb run`. It does
not yet provide a distributable `wb build` command.
